### 旋转偶极子的辐射
#### 题目
+ 求旋转偶极子的辐射。
+ 旋转偶极子：两个振荡偶极子的叠加：

$ \vec{p}(t) = p_0 \left[\hat{e}_x\cos\omega t + \hat{e}_y \cos \left(\omega t - \frac{\pi}{2}\right)\right] $

    - 相应的复数形式：

$ \vec{p}(t) = p_0 \left[\hat{e}_x e^{-i\omega t} + \hat{e}_y e^{-i(\omega t - \frac{\pi}{2})}\right] $

#### 解答
+ 首先回忆$ z $轴上振荡的电偶极子$ \vec{p}(t) = p_0 e^{-i\omega t} \hat{e}_z $产生的电磁场：

$ \vec{B}=\frac{1}{4\pi\epsilon_{0}c^{3}r}|\ddot{\vec{p}}(t)|e^{ikr}\sin~\theta\hat{e}_{\phi}
= -\frac{\mu_0 \omega^2 p_0}{4\pi c} \frac{e^{i(kr-\omega t)}}{r} \sin\theta \hat{e}_\phi $  
$ \vec{E}=\frac{1}{4\pi\epsilon_{0}c^{2}r}|\ddot{\vec{p}}(t)|e^{ikr}\sin\theta\hat{e}_{\theta}= -\frac{\mu_0 \omega^2 p_0}{4\pi} \frac{e^{i(kr-\omega t)}}{r} \sin\theta \hat{e}_\theta $

+ 考虑到单位矢量的关系：

$ \hat{e}_z = \cos\theta \hat{e}_r - \sin\theta \hat{e}_{\theta} $

    - 可以化为：

$ \sin\theta \hat{e}_{\theta} = \cos\theta \hat{e}_r-\hat{e}_z =\frac{z}{r}\hat{e}_r-\hat{e}_z  $

+ 由此电场强度可以化为：

$ \vec{E}=\frac{1}{4\pi\epsilon_{0}c^{2}r}|\ddot{\vec{p}}(t)|e^{ikr}\hat{e}_{\theta}\left(\frac{z}{r}\hat{e}_r-\hat{e}_z \right)
= \frac{\mu_0 \omega^2 p_0}{4\pi} \frac{e^{i(kr-\omega t)}}{r} \hat{e}_\theta\left(\hat{e}_z-\frac{z}{r}\hat{e}_r \right)
 $



+ 此题中，是位于$ x $轴和$ y $轴上的两个电偶极子：
    - 首先根据场强叠加原理计算总电场强度：

$ \vec{E} = \vec{E}_{p_x} + \vec{E}_{p_y} $

$ = \frac{\mu_0 \omega^2 p_0}{4\pi r} \left[ e^{i(kr-\omega t)} (\hat{e}_x - \frac{x}{r} \hat{e}_r) + e^{i(kr-\omega t)+i\pi/2} (\hat{e}_y - \frac{y}{r} \hat{e}_r) \right] $

    - 给出场强实部的平方：

$ (\text{Re}\,\vec{E})^2 = \left( \frac{\mu_0 p_0 \omega^2}{4\pi r} \right)^2 [1 - \sin^2 \theta \cos^2 (kr - \omega t + \phi)] $

    - 然后给出坡印亭矢量时间平均值：

$ \bar{\vec{S}} = \frac{1}{\mu_0 c} \overline{(\text{Re}\,\vec{E})^2} \hat{e}_r = \frac{\mu_0}{c} \left( \frac{p_0 \omega^2}{4\pi r} \right)^2 \left( 1 - \frac{1}{2} \sin^2 \theta \right) \hat{e}_r $

    - 最后积分得到总辐射功率：

$ P = \oint \bar{\vec{S}} \cdot d\vec{a} = \frac{\mu_0 p_0^2 \omega^4}{6\pi c} $

### 短天线的辐射
#### 题目
+ 天线长度$ l\ll \lambda $，电流分布近似线性形式：

$ I(z) = I_0 \left(1-\frac{2}{l}|z|\right),\;\; z< \frac{l}{2} $

    - 求辐射总功率。

#### 解答
+ 首先求出$ \dot{\vec{p}} $：

$ \dot{\vec{p}}(t) = \int \vec{j}(\vec{r}',t)dV' = \int_{-l/2}^{l/2}I(z)dze^{-i\omega t}
= \frac{1}{2}I_0 le^{-i\omega t} $

+ 由此给出：

$ \ddot{\vec{p}} = -i\omega  \frac{1}{2}I_0 le^{-i\omega t} $

$ |\ddot{\vec{p}}| =   \frac{1}{2}I_0 l\omega $

+ 代入电偶极子辐射功率公式：

$ P = \frac{1}{12\pi \epsilon_0 c^3 }|\ddot{\vec{p}}|^2 = \frac{1}{12\pi \epsilon_0 c^3 }\left( \frac{1}{2}I_0 l\omega\right)^2 =\frac{I_0^2 l^2\omega^2}{48\pi \epsilon_0 c^3 } $$$

$ = \frac{\pi}{12} \sqrt{\frac{\mu_0}{\epsilon_0}}I_0^2\left(\frac{l}{\lambda}\right)^2 $

### 求电四极子以频率omega振荡时的辐射功率  
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1778849911755-1c26bd78-dc5f-476c-a5cd-e2656d861b6c.png" width="239.24999286979457" title="" crop="0,0,1,1" id="u3abaa62a" class="ne-image">

+ 首先给出未去迹的电四极矩张量：

$ \overleftrightarrow{Q} = \int \rho_0 (\vec{r}')\vec{r}'\vec{r}'dV' = 2ql^2 \hat{e}_z\hat{e}_z $

+ 代入电四极辐射的单位距离零相位矢势：

$ \vec{A}_{0,e4}^{(2)}
=-\frac{\mu_{0}\omega}{8\pi}\vec{k}\cdot\overleftrightarrow{Q}
= -\frac{\mu_0ck^2}{8\pi}\hat{e}_r\cdot \overleftrightarrow{Q} 
= -\frac{\mu_0ck^2}{4\pi}ql^2\cos\theta \hat{e}_z $

+ 由此计算磁感应强度：

$ \vec{B}^{(2)}_{e4}(\vec{r},t) = i\vec{k}\times\vec{A}_{0,e4}^{(2)} \frac{e^{i(kr-\omega t)}}{r}= ik\hat{e}_r\times \left(-\frac{\mu_0ck^2}{4\pi}ql^2\cos\theta \hat{e}_z \frac{e^{i(kr-\omega t)}}{r}  \right) $

$ \approx -i\frac{\mu_0ck^3}{4\pi}ql^2\cos\theta\sin\theta \frac{e^{i(kr-\omega t)}}{r}e_{\phi} = \vec{B}_0\frac{e^{i(kr-\omega t)}}{r}e_{\phi}  $

+ 辐射功率角分布：

$ \frac{dP}{d\Omega} = \frac{c}{2\mu_0} |\vec{B}_{0,e4}|^2 $

+ 总功率为：

$ P = \int\frac{dP}{d\Omega}d\Omega $

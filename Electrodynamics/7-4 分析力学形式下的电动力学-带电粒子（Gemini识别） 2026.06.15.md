## 复习 - 最小作用量原理 & 拉格朗日方程
对于理想、完整、广义的有势体系，拉格朗日量为 $ L=L(q,\dot{q},t) $。从时刻 $ t_{1} $ 的构型 $ q(t_{1}) $ 运动到时刻 $ t_{2} $ 的构型 $ q(t_{2}) $，粒子的真实运动轨道使得作用量 $ S $ 取极小值（变分为 0）：

$ \delta S = 0 \tag{1} $

$ \text{其中 } S=\int_{t_{1}}^{t_{2}}L(q,\dot{q},t)\text{d}t \tag{2} $

从而得到欧拉-拉格朗日方程：

$ \frac{\partial L}{\partial q}-\frac{\text{d}}{\text{d}t}\frac{\partial L}{\partial\dot{q}}=0 \tag{3} $

若系统有 $ f $ 个自由度 $ q_{i} $ ($ i=1,2,\dots,f $)，则有：

$ \frac{\partial L}{\partial q_{i}}-\frac{\text{d}}{\text{d}t}\frac{\partial L}{\partial\dot{q}_{i}}=0 \quad i=1,2,\dots,f \tag{4} $

## 一、 非相对论带电粒子在电磁场中的拉格朗日量
设一个质量为 $ m $、带电量为 $ q $ 的粒子，在由标势 $ \phi(\vec{r},t) $ 和矢势 $ \vec{A}(\vec{r},t) $ 描述的电磁场中运动。粒子受到的洛伦兹力为：

$ \vec{F} = q(\vec{E} + \vec{v}\times\vec{B}) \tag{5} $

由于洛伦兹力与速度相关，它不是一个传统意义上的保守力（有势力的负梯度）。然而，我们可以引入一个**广义势能（速度相关势）** $ U(\vec{r},\vec{v},t) $，使得洛伦兹力可以用如下广义梯度形式表达：

$ \vec{F} = -\nabla U + \frac{\text{d}}{\text{d}t}\left(\nabla_{v} U\right) \tag{6} $

经过推导，对应的广义势能形式为：

$ U(\vec{r},\vec{v},t) = q\phi(\vec{r},t) - q\vec{v}\cdot\vec{A}(\vec{r},t) \tag{7} $

因此，非相对论带电粒子的拉格朗日量 $ L = T - U $（动能减去广义势能）可以写为：

$ L(\vec{r},\vec{v},t) = \frac{1}{2}m\vec{v}^{2} - q\phi(\vec{r},t) + q\vec{v}\cdot\vec{A}(\vec{r},t) \tag{8} $

### 验证洛伦兹力
将式 (8) 代入欧拉-拉格朗日方程进行验证。以 $ x $ 分量为例：

$ \frac{\partial L}{\partial x} = -q\frac{\partial\phi}{\partial x} + q\left(v_{x}\frac{\partial A_{x}}{\partial x} + v_{y}\frac{\partial A_{y}}{\partial x} + v_{z}\frac{\partial A_{z}}{\partial x}\right) \tag{9} $

$ \frac{\partial L}{\partial v_{x}} = m v_{x} + q A_{x} \tag{10} $

对时间求全导数（注意 $ \vec{A} $ 的时间变化包含显时变和因粒子运动引起的隐时变）：

$ \frac{\text{d}}{\text{d}t}\frac{\partial L}{\partial v_{x}} = m\dot{v}_{x} + q\left(\frac{\partial A_{x}}{\partial t} + v_{x}\frac{\partial A_{x}}{\partial x} + v_{y}\frac{\partial A_{x}}{\partial y} + v_{z}\frac{\partial A_{x}}{\partial z}\right) \tag{11} $

代入方程 $ \frac{\partial L}{\partial x} - \frac{\text{d}}{\text{d}t}\frac{\partial L}{\partial v_{x}} = 0 $ 中，消去相同项后得到：

$ m\dot{v}_{x} = q\left(-\frac{\partial\phi}{\partial x} - \frac{\partial A_{x}}{\partial t}\right) + q\left[v_{y}\left(\frac{\partial A_{y}}{\partial x} - \frac{\partial A_{x}}{\partial y}\right) - v_{z}\left(\frac{\partial A_{x}}{\partial z} - \frac{\partial A_{z}}{\partial x}\right)\right] \tag{12} $

利用电场与磁场的势表达关系 $ \vec{E} = -\nabla\phi - \frac{\partial\vec{A}}{\partial t} $ 以及 $ \vec{B} = \nabla\times\vec{A} $，上式精确地化为：

$ m\dot{v}_{x} = q\left[E_{x} + (\vec{v}\times\vec{B})_{x}\right] \tag{13} $

这证明了拉格朗日量 (8) 的正确性。

## 二、 带电粒子的哈密顿量与广义动量
根据解析力学理论，系统的**广义动量**（或称正则动量）$ \vec{p} $ 定义为拉格朗日量对速度的偏导数：

$ \vec{p} = \nabla_{v} L \implies p_{i} = \frac{\partial L}{\partial v_{i}} \tag{14} $

将式 (8) 代入，可得带电粒子的广义动量为：

$ \vec{p} = m\vec{v} + q\vec{A} \tag{15} $

### ⚠️ 重要物理注记
+ $ \vec{P}_{mech} = m\vec{v} $ 称为**机械动量**（或动力量），它直接对应粒子的物理速度。
+ $ \vec{p} $ 称为**正则动量**（或广义动量），它除了包含机械动量外，还包含了来自电磁矢势的贡献 $ q\vec{A} $。在量子力学中，动量算符 $ \hat{\vec{p}} = -i\hbar\nabla $ 对应的正是这个正则动量。

接下来，通过勒让德变换（Legendre Transformation）构建系统的**哈密顿量** $ H $：

$ H(\vec{r},\vec{p},t) = \vec{p}\cdot\vec{v} - L \tag{16} $

需要注意，哈密顿量必须完全用坐标 $ \vec{r} $ 和正则动量 $ \vec{p} $ 作为自变量来表达。由式 (15) 导出速度：$ \vec{v} = \frac{\vec{p} - q\vec{A}}{m} $，将其代入式 (16)：

$ H = \vec{p}\cdot\left(\frac{\vec{p}-q\vec{A}}{m}\right) - \left[\frac{1}{2}m\left(\frac{\vec{p}-q\vec{A}}{m}\right)^{2} - q\phi + q\left(\frac{\vec{p}-q\vec{A}}{m}\right)\cdot\vec{A}\right] \tag{17} $

化简后得到非相对论带电粒子在电磁场中的标准哈密顿量：

$ H(\vec{r},\vec{p},t) = \frac{(\vec{p} - q\vec{A}(\vec{r},t))^{2}}{2m} + q\phi(\vec{r},t) \tag{18} $

## 三、 相对论性带电粒子的四维协变最小作用量原理
在狭义相对论框架下，时空和电磁势分别组成了标准的四维矢量：

+ 四维时空坐标：$ x_{\mu} = (x_{1}, x_{2}, x_{3}, x_{4}) = (\vec{r}, ict) $
+ 四维电磁势：$ A_{\mu} = (\vec{A}, i\frac{\phi}{c}) $

自由相对论粒子的四维固有时间微元为：$ \text{d}\tau = \sqrt{\text{d}t^{2} - \frac{\text{d}\vec{r}^{2}}{c^{2}}} = \frac{1}{c}\sqrt{-\text{d}x_{\mu}\text{d}x_{\mu}} $。

为了满足洛伦兹协变性（在所有惯性系下形式一致），相对论带电粒子的总作用量 $ S $ 可以写为如下协变积分形式：

$ S = \int_{1}^{2} -m_{0}c \text{d}s + q A_{\mu} \text{d}x_{\mu} \tag{19} $

$ \text{其中 } \text{d}s = \sqrt{-\text{d}x_{\mu}\text{d}x_{\mu}} = c\text{d}\tau \tag{20} $

将各分量展开到普通时间 $ t $ 的积分，以提取常规的拉格朗日量：

$ S = \int_{t_{1}}^{t_{2}} \left( -m_{0}c^{2}\sqrt{1-\frac{\vec{v}^{2}}{c^{2}}} + q\vec{v}\cdot\vec{A} - q\phi \right) \text{d}t \tag{21} $

由此得到**相对论带电粒子的拉格朗日量**为：

$ L = -m_{0}c^{2}\sqrt{1-\frac{\vec{v}^{2}}{c^{2}}} - q\phi + q\vec{v}\cdot\vec{A} \tag{22} $

### 相对论正则动量与哈密顿量
根据广义动量的定义 (14)：

$ \vec{p} = \nabla_{v} L = \frac{m_{0}\vec{v}}{\sqrt{1-\frac{\vec{v}^{2}}{c^{2}}}} + q\vec{A} = \vec{P}_{mech} + q\vec{A} \tag{23} $

对其进行勒让德变换，可求得**相对论带电粒子的哈密顿量**：

$ H = \vec{p}\cdot\vec{v} - L = \frac{m_{0}c^{2}}{\sqrt{1-\frac{\vec{v}^{2}}{c^{2}}}} + q\phi \tag{24} $

利用相对论能量-动量关系消去速度 $ \vec{v} $，用正则动量 $ \vec{p} $ 表达：

$ (H - q\phi)^{2} - (\vec{p} - q\vec{A})^{2}c^{2} = (m_{0}c^{2})^{2} \tag{25} $

$ H(\vec{r},\vec{p},t) = \sqrt{(\vec{p} - q\vec{A}(\vec{r},t))^{2}c^{2} + (m_{0}c^{2})^{2}} + q\phi(\vec{r},t) \tag{26} $

## 四、 协变形式下的变分与运动方程的推导
我们直接在四维时空框架下对作用量表达式 (19) 进行变分，从而推导协变的相对论运动方程。

$ \delta S = \delta \int_{1}^{2} \left( -m_{0}c \sqrt{-\text{d}x_{\mu}\text{d}x_{\mu}} + q A_{\mu} \text{d}x_{\mu} \right) = 0 \tag{27} $

### 1. 第一项（自由粒子项）的变分：
$ \delta \sqrt{-\text{d}x_{\mu}\text{d}x_{\mu}} = \frac{-\text{d}x_{\mu}\delta(\text{d}x_{\mu})}{\sqrt{- \text{d}x_{\nu}\text{d}x_{\nu}}} = -\frac{\text{d}x_{\mu}}{\text{d}s}\text{d}(\delta x_{\mu}) \tag{28} $

利用分部积分法，并将两端固定边界条件 $ \delta x_{\mu}(1) = \delta x_{\mu}(2) = 0 $ 代入：

$ \int_{1}^{2} m_{0}c \frac{\text{d}x_{\mu}}{\text{d}s}\text{d}(\delta x_{\mu}) = \left[m_{0}c\frac{\text{d}x_{\mu}}{\text{d}s}\delta x_{\mu}\right]_{1}^{2} - \int_{1}^{2} m_{0}c \text{d}\left(\frac{\text{d}x_{\mu}}{\text{d}s}\right)\delta x_{\mu} = -\int_{1}^{2} m_{0}c \text{d}\left(\frac{\text{d}x_{\mu}}{\text{d}s}\right)\delta x_{\mu} \tag{29} $

### 2. 第二项（相互作用项）的变分：
由于电磁势 $ A_{\mu}(x) $ 依赖于位置，其变分包含两部分：

$ \delta(A_{\mu}\text{d}x_{\mu}) = (\delta A_{\mu})\text{d}x_{\mu} + A_{\mu}\text{d}(\delta x_{\mu}) = \frac{\partial A_{\mu}}{\partial x_{\nu}}\delta x_{\nu}\text{d}x_{\mu} + A_{\mu}\text{d}(\delta x_{\mu}) \tag{30} $

对第二项同样使用分部积分法：

$ \int_{1}^{2} A_{\mu}\text{d}(\delta x_{\mu}) = [A_{\mu}\delta x_{\mu}]_{1}^{2} - \int_{1}^{2} \text{d}A_{\mu}\delta x_{\mu} = -\int_{1}^{2} \frac{\partial A_{\mu}}{\partial x_{\nu}}\text{d}x_{\nu}\delta x_{\mu} \tag{31} $

为了便于合并同类项，交换指标 $ \mu \leftrightarrow \nu $，式 (30) 的第一项积分可以写为：

$ \int_{1}^{2} \frac{\partial A_{\mu}}{\partial x_{\nu}}\delta x_{\nu}\text{d}x_{\mu} = \int_{1}^{2} \frac{\partial A_{\nu}}{\partial x_{\mu}}\text{d}x_{\nu}\delta x_{\mu} \tag{32} $

由此，电磁相互作用项的总变分积分为：

$ \int_{1}^{2} q \left( \frac{\partial A_{\nu}}{\partial x_{\mu}} - \frac{\partial A_{\mu}}{\partial x_{\nu}} \right) \text{d}x_{\nu}\delta x_{\mu} \tag{33} $

### 3. 合并变分并引入电磁场张量
将式 (29) 和式 (33) 合并到总变分 $ \delta S = 0 $ 中：

$ \int_{1}^{2} \left[ -m_{0}c \text{d}\left(\frac{\text{d}x_{\mu}}{\text{d}s}\right) + q\left(\frac{\partial A_{\nu}}{\partial x_{\mu}} - \frac{\partial A_{\mu}}{\partial x_{\nu}}\right)\text{d}x_{\nu} \right] \delta x_{\mu} = 0 \tag{34} $

由于时空轨道的任意变分 $ \delta x_{\mu} $ 是相互独立的，被积函数必须处处为 0：

$ -m_{0}c \text{d}\left(\frac{\text{d}x_{\mu}}{\text{d}s}\right) + q\left(\frac{\partial A_{\nu}}{\partial x_{\mu}} - \frac{\partial A_{\mu}}{\partial x_{\nu}}\right)\text{d}x_{\nu} = 0 \tag{35} $

我们定义标准的四维**电磁场张量（Field Strength Tensor）** $ F_{\mu\nu} $ 为：

$ F_{\mu\nu} = \frac{\partial A_{\nu}}{\partial x_{\mu}} - \frac{\partial A_{\mu}}{\partial x_{\nu}} \tag{36} $

同时，利用关系 $ \text{d}s = c\text{d}\tau $，方程 (35) 两边同除以 $ \text{d}\tau $，即可改写为：

$ m_{0}\frac{\text{d}^{2}x_{\mu}}{\text{d}\tau^{2}} = q F_{\mu\nu}\frac{\text{d}x_{\nu}}{\text{d}\tau} \tag{37} $

若引入相对论四维速度 $ U_{\mu} = \frac{\text{d}x_{\mu}}{\text{d}\tau} $，则四维协变的运动方程最终表现为：

$ m_{0}\frac{\text{d}U_{\mu}}{\text{d}\tau} = q F_{\mu\nu}U_{\nu} \tag{38} $

### 💡 总结意义
公式 (38) 即为**相对论洛伦兹力公式的四维协变表达形式**。通过最小作用量原理的四维变分，我们不仅以极其优雅的方式导出了带电粒子在电磁场中的运动规律，更深刻地揭示了电磁相互作用的几何性质：电磁场张量 $ F_{\mu\nu} $ 本质上作为时空的一种微扰源，完美地支配着带电世界里物质的运动测地线。

### 闵氏四维时空与四维时空矢量
#### 洛伦兹变换的矩阵形式
+ 洛伦兹变换为：

$ x' = \frac{x-vt}{\sqrt{1-v^2/c^2}} $

$ y' = y $

$ z' = z $

$ t' = \frac{t-vx/c^2}{\sqrt{1-v^2/c^2}} $

+ 可以写成更加有启发的形式：

$ x' = \gamma(x-\beta ct) $

$ y' = y $

$ z' = z $

$ ct' = \gamma(ct-\beta x) $

    - 其中：

$ \beta = \frac{v}{c},\;\; \gamma = \frac{1}{\sqrt{1-\beta^2}} $

+ 此时，使用$ 1234 $的符号规定，令：

$ x_1 := x,\;x_2 := y,\;x_3 := z,\; x_4 := ict $

    - 此时，洛伦兹变换可以写成矩阵形式：

$ \begin{pmatrix}x' \\ y' \\ z' \\ ict' \end{pmatrix} = \begin{pmatrix}\gamma & 0 & 0 & i\beta \gamma \\ 0 & 1 & 0 & 0 \\ 0 & 0 & 1 & 0 \\ -i\beta \gamma & 0 & 0 & \gamma \end{pmatrix} \begin{pmatrix}x \\ y \\ z \\ ict \end{pmatrix} $

    - 即：

$ \begin{pmatrix}x_1' \\ x_2' \\ x_3' \\ x_4' \end{pmatrix} = \begin{pmatrix}\gamma & 0 & 0 & i\beta \gamma \\ 0 & 1 & 0 & 0 \\ 0 & 0 & 1 & 0 \\ -i\beta \gamma & 0 & 0 & \gamma \end{pmatrix} \begin{pmatrix}x_1 \\ x_2 \\ x_3 \\ x_4 \end{pmatrix} $

#### 洛伦兹变换的指标表述
+ $ x_\mu $是洛伦兹矢量，或者称为4-矢量。准确而言其实$ x_\mu $是四矢量的坐标值，而非四矢量本身。
+ 对于上述线性变换，可以使用指标形式来描述：

$ x'_\mu = L_{\mu\nu}x_\nu $

    - 注意，其中爱因斯坦求和约定生效。
    - $ \mu,\nu = 1,2,3,4 $
    - 洛伦兹变换矩阵的矩阵元为：

$  (L_{\mu\nu}) = \begin{pmatrix}\gamma & 0 & 0 & i\beta \gamma \\ 0 & 1 & 0 & 0 \\ 0 & 0 & 1 & 0 \\ -i\beta \gamma & 0 & 0 & \gamma \end{pmatrix} $

+ 对于距离微元，可以改写成：

$ dx'_\mu = L_{\mu\nu}dx_\nu $

#### 洛伦兹变换的性质
+ 间隔不变性：四矢量本身应该在洛伦兹变换下模长不变，即间隔不变性：

$ x_\mu' x_\mu' = x_\nu x_\nu $

+ 间隔不变性对于洛伦兹变换矩阵本身有一定的要求，即$ L $是正交的复矩阵。
    - 正交的复矩阵有些特殊，它既不是正交实矩阵，又不是幺正矩阵。这种不自然性来自于$ x_4 := ict $规定的不自然性。
    - 下面给出证明：

$ x_\mu' x_\mu' = L_{\mu\nu}x_\nu L_{\mu\lambda}x_\lambda =  L_{\mu\nu}L_{\mu\lambda}x_\nu x_\lambda $

    - 第一个等号是洛伦兹变换的定义，第二个等号是因为这是分量的表达式，可以交换顺序。
    - 根据间隔不变性，可知：

$ x_\mu' x_\mu' =L_{\mu\nu}L_{\mu\lambda}x_\nu x_\lambda = x_\nu x_\nu $

$ \Rightarrow L_{\mu\nu}L_{\mu\lambda} = \delta_{\nu\lambda} $

$ \Rightarrow (L^T)_{\nu\mu}L_{\mu\lambda} = \delta_{\nu\lambda} $

        * 写成矩阵形式，就是：

$ L^T L = I $

    - 这正是正交矩阵的定义！

$ \mathrm{Q.E.D.} $

### 洛伦兹（四维）标量、矢量、张量
#### 洛伦兹协变量
+ 记号约定，$ S\rightarrow S' $系变换下，$ S $系物理量观察结果为$ A $，$ S' $系对应物理量观察结果为$ A' $。
+ 四维标量：
    - 变换性质：在洛伦兹变换下不变
    - 举例：电荷量、静质量

$ m \rightarrow m' = m $

+ 四维矢量：
    - 变换性质：满足洛伦兹变换，用洛伦兹矩阵描述
    - 举例：四维微商算符，四速度

$ V_\mu \rightarrow  V_\mu' = L_{\mu\nu}V_{\nu} $

        * 写成矩阵形式：

$ V \rightarrow V' = L\cdot V $

+ 四维张量（准确来说是二阶张量）：
    - 满足洛伦兹变换，用两个洛伦兹矩阵描述
    - 举例:：能动量张量

$ T_{\mu\nu} = T'_{\mu\nu} = L_{\mu\rho}L_{\nu\sigma}T_{\rho\sigma} $

        * 写成矩阵形式：

$ T \rightarrow T' = LL: T $

#### 元间隔是洛伦兹标量
+ 元间隔的定义为$ dx_{\mu}dx_{\mu} $
+ 证明：
    - 根据$ x'_\mu = L_{\mu\nu}x_\nu $可知：$ dx'_\mu = L_{\mu\nu}dx_\nu $
    - 因此：

$ dx_{\mu}'dx_{\mu}' = L_{\mu\nu}dx_\nu L_{\mu\lambda}dx_\lambda = L_{\mu\nu}L_{\mu\lambda}dx_\nu dx_\lambda = \delta_{\nu\lambda}dx_\nu dx_\lambda = dx_\nu dx_\nu $

        * 第三个等号用到了洛伦兹变换矩阵的性质：$ L_{\mu\nu}L_{\mu\lambda}= \delta_{\nu\lambda} $。

$ \mathrm{Q.E.D.} $

+ 根据这个可以定义**不变间隔**$ ds^2 $：

$ dx_{\mu}'dx_{\mu}' = dx_\mu dx_\mu  = dx^2+dy^2+dz^2 - c^2dt^2 := -ds^2 $

+ 可以进一步定义**固有时**$ \tau $：

$ ds^2 := c^2 d\tau^2 $

#### 四维速度是洛伦兹矢量
+ 首先定义四速度：

$ U_\mu = \frac{dx_\mu}{d\tau} = \left(\frac{d\vec{x}}{d\tau},ic\frac{dt}{d\tau}\right) $

+ 下面证明四速度为洛伦兹不变量：

$ S\rightarrow S' $

$ dx_\mu \rightarrow dx_\mu' = L_{\mu\nu}dx_\nu $

$ d\tau \rightarrow d\tau' = d\tau $

    - 最后一行用到了$ d\tau $是洛伦兹标量。
    - 有了上面的准备可以给出四速度的变换公式：

$ U_\mu \rightarrow U_\mu' = \frac{dx_\mu'}{d\tau'} = L_{\mu\nu}\frac{dx_\nu}{d\tau} = L_{\mu\nu}U_\nu $

    - 这个式子满足洛伦兹矢量变换公式：

$ V \rightarrow V' = L\cdot V $

$ \mathrm{Q.E.D.} $

+ 下面讨论四速度与三速度的关系：

$ U_\mu = \frac{dx_\mu}{d\tau} = \left(\frac{d\vec{x}}{d\tau},ic\frac{dt}{d\tau}\right)
 = \frac{dt}{d\tau} \left(\frac{d\vec{x}}{dt},ic\frac{dt}{dt}\right)  =\gamma \left(\vec{v},ic\right)  $

+ 四速度有归一化条件：

$ U_\mu U_\mu   =\gamma \left(\vec{v},ic\right) \cdot\gamma \left(\vec{v},ic\right) = \gamma^2(v^2 - c^2) = \frac{v^2-c^2}{1-v^2/c^2} = -c^2 $

#### 四维微商算符是洛伦兹矢量
+ 首先定义四维微商算符：

$ \partial_\mu = \left(\nabla,\frac{1}{ic}\frac{\partial}{\partial t}\right) =\left(\frac{\partial}{\partial x},\frac{\partial}{\partial y},\frac{\partial}{\partial z},\frac{1}{ic}\frac{\partial}{\partial t}\right) $

+ 下面证明四维微商算符是洛伦兹不变量：
    - 设洛伦兹变换矩阵为 $ L $，其元素满足正交性 $ L_{\lambda\mu} L_{\lambda\nu} = \delta_{\mu\nu} $（即 $ L^T L = I $，所以 $ L^{-1} = L^T $）。
    - 正变换：

$ x'_\mu = L_{\mu\nu} x_\nu \implies \frac{\partial x'_\mu}{\partial x_\nu} = L_{\mu\nu} $

    - 逆变换： 首先写出：

$ x'_\mu = L_{\mu\nu} x_\nu  $

$ \Rightarrow (L^{-1})_{\rho \mu} x_\mu' = (L^{-1})_{\rho \mu} L_{\mu\nu} x_\nu $

        * 根据洛伦兹矩阵是复正交矩阵：

$ L^{-1} = L^{T} $

$ \Rightarrow (L^{-1})_{\rho\mu} = (L^{T})_{\rho\mu} = L_{\mu\rho} $

$ \Rightarrow L_{\mu\rho} x'_\mu = L_{\mu\rho} L_{\mu\nu} x_\nu = \delta_{\rho\nu} x_\nu = x_\rho $

        * 调换字母后即：

$ x_\nu = L_{\mu\nu} x'_\mu \implies \frac{\partial x_\nu}{\partial x'_\mu} = L_{\mu\nu} $

        * 代入链式法则：

$ \partial'_\mu = \frac{\partial}{\partial x'_\mu} = \frac{\partial x_\nu}{\partial x'_\mu} \frac{\partial}{\partial x_\nu} = L_{\mu\nu} \partial_\nu $

$ \mathrm{Q.E.D.} $

+ 此外，还可以推导出新的结论：

$ \partial_{\mu}'\partial_{\mu}' = L_{\mu\nu}\partial_\nu L_{\mu\lambda}\partial_\lambda = L_{\mu\nu}L_{\mu\lambda}\partial_\nu \partial_\lambda = \delta_{\nu\lambda}\partial_\nu \partial_\lambda = \partial_\nu \partial_\nu $

    - 可以引入**达朗贝尔算符**，它是一个标量算符：

$ \square := \partial_\mu\partial_\mu = \nabla^2 - \frac{1}{c^2}\frac{\partial^2}{\partial t^2} $

#### 补充：易错辨析
+ 之所以直接除是不正确的，可以这么理解：

$ x'_\mu = L_{\mu\nu} x_\nu  $

    - 两边取微分：

$  dx'_\mu = L_{\mu\nu} dx_\nu $

    - 根据多元函数求导法则：

$  dx'_\mu =\frac{\partial x'_\mu}{\partial x_\nu} dx_\nu $

$ \Rightarrow L_{\mu\nu} = \frac{\partial x'_\mu}{\partial x_\nu} $

+ $  dx'_\mu = L_{\mu\nu} dx_\nu $的本质其实是：

$  dx'_\mu = \sum_{\nu = 0}^{4}L_{\mu\nu} dx_\nu $

    - 直接把$ L_{\mu\nu} $除过去显然是没有道理的，因为这里涉及求和。
    - 正确的方法是使用逆矩阵：

$  (L^{-1})_{\rho\mu}dx'_\mu = (L^{-1})_{\rho\mu}L_{\mu\nu} dx_\nu $

$ \Rightarrow L_{\mu\rho}dx'_\mu = dx_\rho $

$ \Rightarrow L_{\mu\nu}dx'_\mu = dx_\nu $

#### 四维波矢是洛伦兹矢量
+ 首先定义四维波矢：

$ k_\mu = \left(\vec{k},i\frac{\omega}{c}\right) $

+ 下面证明四维波矢量是洛伦兹矢量：
    - 首先给出波矢的洛伦兹变换形式：

$ k_\mu' = L_{\mu\nu}k_\nu $

    - 然后考虑其与矢量内积：

$ k_\mu' x_\mu'= L_{\mu\nu}k_\nu L_{\mu\rho}x_\rho = \delta_{\nu\lambda}k_\nu x_\rho = k_\nu x_\nu $

$ \mathrm{Q.E.D.} $

### 四维标量场、矢量场、张量场
+ 洛伦兹变换：

$ S\rightarrow S' $

+ 标量场变换：

$ \phi(x)\rightarrow \phi'(x') = \phi(x) $

+ 矢量场变换：

$ A_\mu(x)\rightarrow A_\mu'(x') = L_{\mu\nu}A_\nu(x) $

+ 张量场变换：

$ F_{\mu\nu}(x)\rightarrow F_{\mu\nu}'(x') = L_{\mu\rho} L_{\nu\sigma}F_{\rho\sigma}(x) $

### 相对性原理的四维表述
+ 相对性原理：所有物理规律在不同惯性参考系中形式相同。
+ 例子：电荷守恒方程：

$ \frac{\partial \rho}{\partial t} +\nabla\cdot \vec{j} = 0 $

$ \frac{1}{ic}\frac{\partial}{\partial t}(ic\rho) +\nabla\cdot \vec{j} = 0 $

    - 之前定义了：

$ \partial_\mu = \left(\nabla,\frac{1}{ic}\frac{\partial}{\partial t}\right) =\left(\frac{\partial}{\partial x},\frac{\partial}{\partial y},\frac{\partial}{\partial z},\frac{1}{ic}\frac{\partial}{\partial t}\right) $

    - 如果进行定义：

$ j_\mu = \left(\vec{j},ic\rho\right)  $

    - 那么有：

$ \partial_\mu j_\mu = 0 $

+ 下面给出协变性的证明：

$ 0=\partial_\mu' j_\mu'(x') = L_{\mu\nu}\partial_\nu L_{\mu\rho}j_\rho(x) = \delta_{\nu\rho}\partial_\nu j_{\rho} =\partial_\nu j_{\nu}(x)  $

+ 综上，如果接受$ S $系中电荷守恒$ \partial_\mu j_\mu = 0 $，那么$ S' $系中电荷守恒表述方式形式相同$ \partial_\mu' j_\mu' = 0 $。

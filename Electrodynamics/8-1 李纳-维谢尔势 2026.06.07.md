### 复习：推迟势
+ 洛伦茨规范：

$ \nabla \cdot \vec{A} + \frac{1}{c^2} \frac{\partial\phi}{\partial t} = 0 $

+ 在洛伦茨规范下，连续分布的电荷电流分布$ \rho (\vec{r},t),\vec{j}(\vec{r},t) $产生的电磁势场$ \phi(\vec{r},t),\vec{A}(\vec{r},t) $满足的偏微分方程为：

$ \nabla^2 \phi -\frac{1}{c^2}\frac{\partial^2\phi}{\partial t^2} = -\frac{\rho}{\epsilon_0} $

$ \nabla^2 \vec{A} -\frac{1}{c^2}\frac{\partial^2\vec{A}}{\partial t^2} = -\mu_0\vec{j} $

    - 这两个方程都是三维的波动方程，描述的是点的局域效应。
+ 考虑三维波动方程的推迟格林函数$ G(\vec{r},t;\vec{r}',t') $：

$ \nabla^2 G(\vec{r},t;\vec{r}',t') - \frac{1}{c^2} \frac{\partial^2G}{\partial t^2} = -\delta^{(3)} (\vec{r}-\vec{r}')\delta (t-t') $

    - 推迟格林函数解为：

$ G(\vec{r},t;\vec{r}',t') = \frac{\delta (t-t' -|\vec{r}-\vec{r}'|/c)}{4\pi |\vec{r}-\vec{r}'|} $



+ 由此写出偏微分方程的解：

$  \phi(\vec{r},t) =  \iint \frac{\rho(\vec{r}',t')}{\epsilon_0} G(\vec{r},t;\vec{r}',t') dV' dt' $

$ = \frac{1}{\epsilon_0}\int_{-\infin}^{t}dt'\int_{V'}dV' \rho(\vec{r}',t')\frac{\delta (t-t' -|\vec{r}-\vec{r}'|/c)}{4\pi |\vec{r}-\vec{r}'|} $ 

$ =  \frac{1}{4\pi\epsilon_0}\int_{V'}dV' \frac{\rho(\vec{r}',t-|\vec{r}-\vec{r}'|/c)}{ |\vec{r}-\vec{r}'|} $

    - 以及：

$  \vec{A}(\vec{r},t) =\iint \mu_0\vec{j}(\vec{r}',t') G(\vec{r},t;\vec{r}',t') dV' dt' $

$ = \mu_0\int_{-\infin}^{t}dt'\int_{V'}dV' \vec{j}(\vec{r}',t')\frac{\delta (t-t' -|\vec{r}-\vec{r}'|/c)}{4\pi |\vec{r}-\vec{r}'|}
 $

$ =  \frac{\mu_0}{4\pi}\int_{V'}dV' \frac{\vec{j}(\vec{r}',t-|\vec{r}-\vec{r}'|/c)}{ |\vec{r}-\vec{r}'|} $

### 推迟势对源时间积分推到李纳-维谢尔势
#### 运动点电荷的电荷与电流密度场
+ 对于一个电荷量为$ e $，运动轨迹为$ \vec{r} = \vec{r}(t) $的点电荷，其**电荷密度场场空间形式**为：

$ \rho(\vec{r},t) = e\delta (\vec{r}-\vec{r}_e(t)) $

    - 其中$ \vec{r}_e $是引入的哑变量，之后在积分中会消失。它的名字叫做推迟位置。
+ **电流密度场场空间形式**为：

$ \vec{j}(\vec{r},t) = \vec{v}(t)\rho(\vec{r},t) = e\delta (\vec{r}-\vec{r}_e(t))\dot{\vec{r}}(t) $

#### 代入电磁势积分表达式
+ 想用积分方法要求$ \phi(\vec{r},t),\vec{A}(\vec{r},t) $的表达式，需要首先将电荷密度场和电流密度场**转写到源空间形式**：

$ \rho(\vec{r}',t') = e\delta (\vec{r}'-\vec{r}_e(t')) $

$ \vec{j}(\vec{r}',t') =  e\delta (\vec{r}'-\vec{r}_e(t'))\dot{\vec{r}}'(t') $



+ 代入积分表达式：

$ \phi(\vec{r},t) = \frac{1}{4\pi\epsilon_0}\int_{-\infin}^{t}dt'\int_{V'}dV' \rho(\vec{r}',t')\frac{\delta (t-t' -|\vec{r}-\vec{r}'|/c)}{ |\vec{r}-\vec{r}'|}
 $

$  = \frac{1}{4\pi\epsilon_0}\int_{-\infin}^{t}dt'\int_{V'}dV'  e\delta (\vec{r}'-\vec{r}_e(t'))\frac{\delta (t-t' -|\vec{r}-\vec{r}'|/c)}{ |\vec{r}-\vec{r}'|}
 $

#### 对源空间 空间部分 积分
+ 首先**对于源空间的空间部分进行积分**：

$ RHS = \frac{e}{4\pi\epsilon_0}\int_{-\infin}^{t}dt'\frac{\delta (t-t' -|\vec{r}-\vec{r}_e(t')|/c)}{ |\vec{r}-\vec{r}_e(t')|}
 $

#### 对源空间 时间部分 积分
+ <font style="color:#DF2A3F;">对于</font>**<font style="color:#DF2A3F;">源空间的时间部分积分</font>**<font style="color:#DF2A3F;">需要特别注意，因为</font>$ \vec{r}_e(t') $<font style="color:#DF2A3F;">也是显含</font>$ t' $<font style="color:#DF2A3F;">的。</font>
    - 使用性质$ \delta(x) = \delta(-x) $：

$ RHS
= \frac{e}{4\pi\epsilon_0}\int_{-\infin}^{t}dt'\frac{\delta (t'-t +|\vec{r}-\vec{r}_e(t')|/c)}{ |\vec{r}-\vec{r}_e(t')|} $

    - 利用公式：

$ \int f(x)\delta (\phi(x))dx = \sum_{i} \frac{f(x_i)}{|\phi'(x_i)|}|_{x_i为\phi(x)的零点} $

        * 可以得到：

$ RHS = \frac{e}{4\pi\epsilon_0}\frac{1}{ |\vec{r}-\vec{r}_e(t')|} \frac{1}{\frac{d}{dt'}(t'-t +|\vec{r}-\vec{r}_e(t')|/c)}|_{t' = t- |\vec{r}-\vec{r}_e(t')|/c}
 $

$ = \frac{e}{4\pi\epsilon_0}\frac{1}{ |\vec{r}-\vec{r}_e(t')|} \frac{1}{1+\frac{1}{c}\frac{d}{dt'}|\vec{r}-\vec{r}_e(t')|}|_{t' = t- |\vec{r}-\vec{r}_e(t')|/c}
 $

#### 引入推迟距离R
+ 定义：

$ \vec{R}(t') := \vec{r}-\vec{r}_e(t') $

$ R(t') : = |\vec{R}| = |\vec{r}-\vec{r}_e(t')| $

    - 式子可以化为：

$ RHS= \frac{e}{4\pi\epsilon_0}\frac{1}{R(t')} \frac{1}{1+\frac{1}{c}\frac{d}{dt'}R(t')}|_{t' = t- R/c}
 $

+ 下面证明一个式子：

$ \frac{d}{dt}R(t') = \frac{d}{dt}|\vec{R}| = \frac{d}{dt}|\vec{r}-\vec{r}_e(t')|=\frac{d}{dt}\sqrt{[\vec{r}-\vec{r}_e(t')]^2} $

$ \frac{1}{2} \frac{\frac{d}{dt'}[\vec{r}-\vec{r}_e(t')]^2}{\sqrt{[\vec{r}-\vec{r}_e(t')]^2}} = \frac{(\vec{r}-\vec{r}_e(t'))\cdot \frac{d}{dt}(\vec{r}-\vec{r}_e(t'))}{|\vec{r}-\vec{r}_e(t')|} $

$ = \frac{-\vec{R}(t')\cdot \frac{d}{dt}(\vec{r}_e(t'))}{R(t')} = \frac{-\vec{R}(t')\cdot \vec{v}(t')}{R(t')} $

    - 将这个式子代入：

$ RHS= \frac{e}{4\pi\epsilon_0}\frac{1}{R(t')} \frac{1}{1+\frac{1}{c}\frac{-\vec{R}(t')\cdot \vec{v}(t')}{R(t')}}|_{t' = t- R/c}
 $

 $  = \frac{e}{4\pi\epsilon_0}\frac{1}{R(t')} \frac{1}{1-\frac{\vec{R}(t')\cdot \vec{v}(t')}{cR(t')}}|_{t' = t- R/c} $

#### 结果
+ 整理得到：

$ \phi= \frac{1}{4\pi \epsilon_0} \frac{e}{R\left(1 - \frac{\vec{v}(t')\cdot \vec{R}}{cR}\right)}|_{t' = t- R/c} $

    - 类似地：



$ \vec{A} = \frac{\mu_0}{4\pi } \frac{e\vec{v}(t')}{R\left(1 - \frac{\vec{v}(t')\cdot \vec{R}}{cR}\right)}|_{t' = t- R/c} $

### 使用洛伦兹变换推导李纳-维谢尔势
#### 情景假设与符号规定
+ 问题：在一个惯性系$ S $内，有一个点电荷$ e $运动，求其在$ S $系中产生的电磁势$ \phi,\vec{A} $。
+ 符号规定：
    - 定义：
        * 场点事件：探测器探测电磁势大小的事件。
        * 源点事件：点电荷发射出产生探测器探测到的场点事件电磁势的事件。
    - 惯性系$ S $内，场点（考察对象）时空坐标$ \vec{r},t $，源点（点电荷位置）时空坐标$ \vec{r}',t' $
    - 与点电荷瞬时共动的惯性参考系$ \tilde{S} $，点电荷位于$ \tilde S $的原点处。
        * 场点的时空坐标$ \tilde{\vec{r}},\tilde{t} $，源点的时空坐标$ \tilde{\vec{r}'},\tilde{t'} $，场点的电磁势$ \tilde{\phi},\tilde{\vec{A}} $
        * 瞬时共动的惯性参考系：瞬时共动，说明在$ \tilde S $中电磁势的表达式较为简单，惯性参考系说明历史上和未来本质上都是惯性参考系，因此可以使用洛伦兹变换。
    - 场点与源点的空间相对位置：惯性系$ S $中$ \vec{R} = \vec{r}-\vec{r}' $，惯性系$ \tilde S $中$ \tilde{\vec{R}} = \tilde{\vec{r}}-\tilde{\vec{r}'} $。
    - 空间相对位置的大小：：惯性系$ S $中$ R : = |\vec{R}| = |\vec{r}-\vec{r}'| $，惯性系$ \tilde S $中$ \tilde{R} = |\tilde{\vec{R}}| := |\tilde{\vec{r}}-\tilde{\vec{r}'}| $。

#### 推导思路
+ 先从惯性系$ \tilde{S} $入手，求出$ \tilde{\phi},\tilde{\vec{A}} $的表达式，表达式中含有$ \tilde R $。
+ 使用洛伦兹变换，根据$ \tilde{\phi},\tilde{\vec{A}} $求出$ \phi,\vec{A} $，此时$ \phi,\vec{A} $表达式中仍然含有$ \tilde R $。
+ 使用洛伦兹逆变换，使用$ \vec{R} $表示出$ \tilde{\vec{R}} $进一步表示出$ \tilde R $。
    - 其中需要用到：

$ R  = |\vec{r}-\vec{r}'| = c(t-t') $

$ \tilde{R} = |\tilde{\vec{r}}-\tilde{\vec{r}'}| = c(\tilde{t}-\tilde{t'}) $

    - 这两个式子的意思是：在$ S $系中，场点和源点的空间距离$ |\vec{r}-\vec{r}'| $，等于推迟时间$ (t-t') $乘以光速。在$ \tilde{S} $系中，场点和源点的空间距离$ |\tilde{\vec{r}}-\tilde{\vec{r}'}| $，等于推迟时间乘以光速$ (\tilde{t}-\tilde{t'}) $。
    - 注意，在讨论空间距离和推迟时间时，一定要选用相同的参考系的坐标讨论，否则不配套没有意义。

#### 推导过程
+ 在瞬时共动参考系$ \tilde{S} $中，场点对应的电磁势为：

$ \tilde{\phi} = \frac{1}{4\pi \epsilon_0} \frac{e}{\tilde{R}} $

$ \tilde{\vec{A}} = \vec{0} $

    - 后者不妨写成：

$ \tilde{\vec{A}}_{⊥} = \vec{0} $

$ \tilde{\vec{A}}_{∥} = \vec{0} $

+ 根据电磁势的洛伦兹逆变换：

$ \phi = \gamma(\tilde{\phi}+\vec{v}\cdot \tilde{\vec{A}})  = \gamma(\tilde{\phi}+v \tilde{A}_{∥})  $

$ \vec{A}_{∥}= \gamma(\tilde{\vec{A}}_{∥} + \frac{\vec{v}}{c^2}\tilde{\phi}) $

$ \vec{A}_{⊥}= \tilde{\vec{A}}_{⊥} $

    - 将洛伦兹逆变换代入到本题中：

$ \phi=\gamma(\tilde{\phi}+v \tilde{A}_{∥}) = \frac{e}{4\pi \epsilon_0} \frac{\gamma}{\tilde{R}} $

$ \vec{A}_{∥}= \gamma(\tilde{\vec{A}}_{∥} + \frac{\vec{v}}{c^2}\tilde{\phi}) = \frac{\gamma \vec{v}}{c^2}\tilde{\phi} $

$ \vec{A}_{⊥}= \tilde{\vec{A}}_{⊥}=\vec{0} $

        * 后面两个式子可以写成：

$ \vec{A}=\frac{ \vec{v}}{c^2}\tilde{\phi} = \frac{\vec{v}}{c^2}\frac{e}{4\pi \epsilon_0} \frac{\gamma}{\tilde{R}} $

    - 可见，如果能求出$ \phi $的表达式，$ \vec{A} $的表达式自然就写出来了。



+ 下面先求$ \phi $的表达式：

$ \phi= \frac{e}{4\pi \epsilon_0} \frac{\gamma}{\tilde{R}} =  \frac{e}{4\pi \epsilon_0} \frac{\gamma}{\tilde{R}}  $

    - 我们希望都用$ S $中的坐标表示，但是$ \tilde{R} $是$ \tilde{S} $系中的间隔，我们需要处理它：

$ \tilde{R} = |\tilde{\vec{r}}-\tilde{\vec{r}'}| = c(\tilde{t}-\tilde{t'}) =c\tilde{t}-c\tilde{t'} $

+ 根据坐标的洛伦兹变换：

$ c\tilde{t} = \gamma(ct - \vec{v}\cdot \vec{r})=\gamma(ct - \frac{\vec{v}}{c}\cdot \vec{r}_{∥}) $

$ \tilde{\vec{r}}_{∥} = \gamma(\vec{r}_{∥} - \vec{v}t) $

$ \tilde{\vec{r}}_{⊥} =\vec{r}_{⊥}  $

    - 将洛伦兹变换代入本题$ \tilde{R} $的表达式中：

$ \tilde{R}  =c\tilde{t}-c\tilde{t'}=\gamma(ct - \frac{\vec{v}}{c}\cdot \vec{r})-\gamma(ct' - \frac{\vec{v}}{c}\cdot \vec{r}') $

$ =\gamma(ct - ct')-\gamma(\frac{\vec{v}}{c}\cdot \vec{r}- \frac{\vec{v}}{c}\cdot \vec{r}') $

$ =\gamma(ct - ct')-\gamma\frac{\vec{v}}{c}\cdot ( \vec{r}- \vec{r}') $

    - 考虑到定义$ \vec{R} = \vec{r}-\vec{r}' $，$ R  = |\vec{r}-\vec{r}'| = c(t-t') $，并注意字母顺序：

$ \tilde{R}  =\gamma R - \gamma \frac{\vec{v}\cdot \vec{R}}{c} = \gamma R\left(1 - \frac{\vec{v}\cdot \vec{R}}{cR}\right) $

+ 将这个式子代入$ \phi $的表达式：

$ \phi= \frac{e}{4\pi \epsilon_0} \frac{\gamma}{\tilde{R}} =  \frac{e}{4\pi \epsilon_0} \frac{\gamma}{ \gamma R\left(1 - \frac{\vec{v}\cdot \vec{R}}{cR}\right)} = \frac{1}{4\pi \epsilon_0} \frac{e}{R\left(1 - \frac{\vec{v}\cdot \vec{R}}{cR}\right)} $

    - 再将$ \phi $的表达式代入$ \vec{A} $的表达式：

$ \vec{A}=\frac{ \vec{v}}{c^2}\tilde{\phi} = \frac{\vec{v}}{c^2}\frac{1}{4\pi \epsilon_0} \frac{e}{R\left(1 - \frac{\vec{v}\cdot \vec{R}}{cR}\right)} = \frac{\mu_0}{4\pi } \frac{e\vec{v}}{R\left(1 - \frac{\vec{v}\cdot \vec{R}}{cR}\right)} $



+ 考虑到$ \tilde{S} $系是在$ S $系处于$ t' $时刻的共动参考系（即电荷产生被探测器接收到的电磁势的时刻，即源点时刻），因此更严谨的写法为：

$ \phi= \frac{1}{4\pi \epsilon_0} \frac{e}{R\left(1 - \frac{\vec{v}(t')\cdot \vec{R}}{cR}\right)} $

$ \vec{A} = \frac{\mu_0}{4\pi } \frac{e\vec{v}(t')}{R\left(1 - \frac{\vec{v}(t')\cdot \vec{R}}{cR}\right)} $

### 拓展讨论：电荷与电流
+ 我们来看介质中的麦克斯韦方程组：

$ \nabla \cdot \vec{D} = \rho_{自由} $

$ \nabla \times \vec{E} = -\frac{\partial \vec{B}}{\partial t} $

$ \nabla\cdot \vec{B} = 0 $

$ \nabla\times \vec{H} = \vec{f}_{自由}+\frac{\partial \vec{D}}{\partial t} $

+ 那么，如果有一束带正电的自由粒子流从空间流过，显然有：

$ \vec{f}_{自由} \neq \vec{0} $

+ 令人困惑的在于，是否有：

$ \rho_{自由} \neq 0 $？



+ 答案是肯定的，可以从下面的例子中看出：
    - 如果这些整带正电的自由粒子流形成一个半径为$ R $的圆环，那么它们显然会产生磁场。但是会不会产生电场呢？
    - 考虑$ R\rightarrow 0 $的情形，此时不存在净电流，等效于一个静止的点电荷，点电荷的电荷量等于原来粒子流中所有带电粒子的电荷量总和。此时显然会在外界产生电场，即：

$ \rho_{自由} \neq 0 $

+ **可以看出：“电流”与“带电粒子流”是两个概念。**
    - **“电流”强调的是“流”的性质。**
    - **“带电粒子流”既有“流”的性质，又有“荷”的性质。**



+ 在题目中可能引入抽象的对电荷密度场无贡献，但是对电流密度场有贡献的“电流”，例如下面这道题：

<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1780821580996-8f187fa2-b7cb-4bf1-a730-6bf436460073.png" width="564" title="" crop="0,0,1,1" id="u6da5c8e0" class="ne-image">

+ 此时可以认为：带正电的粒子流沿着$ z $轴正方向运动，同时包裹着一层等线电荷密度的负电荷薄层，这时电流密度不为零，但是电荷密度为零。
+ 或者：认为这是一根导线，带负电的电子定向运动，带等量正电的原子实固定在原位。
    - 此时电子们产生了电流，但是原子实没有产生电流，因此电流密度非零。
    - 在某个时刻，单位体积内的电子电荷密度和原子实的电荷密度等大反号，因此每个位置的净电荷密度都是零。
+ **在实际解决问题时，要看清题目指的是抽象的“流”和“荷”，还是具体的“带电粒子流”和“带电粒子”。**
    - **“带电粒子流”和“带电粒子”应该都同时具有“流”和“荷”的性质。**

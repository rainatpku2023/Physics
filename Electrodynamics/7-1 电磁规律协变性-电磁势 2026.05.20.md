### 复习：电磁势满足的微分方程
+ 首先给出真空中的麦克斯韦方程组，进行一定的重新编排：

$ \nabla \cdot \vec{E} = \frac{\rho}{\epsilon_0} \tag{1} $

$ \nabla\times\vec{E} + \frac{\partial \vec{B}}{\partial t} = \vec{0} \tag{2} $

$ \nabla \cdot \vec{B} = 0 \tag{3} $

$ \nabla\times \vec{B} -\frac{1}{c^2} \frac{\partial \vec{E}}{\partial t}=\mu_0 \vec{j} \tag{4} $

+ 根据$ (2)(3) $式，可以引入标量势$ \phi $和矢量势$ \vec{A} $，满足：

$ \vec{B} = \nabla \times \vec{A} $

$ \vec{E} = -\frac{\partial \vec{A}}{\partial t} - \nabla \phi $

+ 电磁势满足微分方程为：

$ \nabla^2 \phi - \frac{1}{c^2}\frac{\partial^2 \phi}{\partial t^2} = -\frac{\rho}{\epsilon_0} $

$ \nabla^2 \vec{A} - \frac{1}{c^2}\frac{\partial^2 \vec{A} }{\partial t^2} = -\mu_0\vec{j} $

+ [1-4 麦克斯韦方程组的对称性 2026.03.18](https://dengbaiyu2023.yuque.com/org-wiki-dengbaiyu2023-vsgo6q/lzpma1/gey4xziqblk6cf0x#vJ7wF)中提到，经典电动力学引入标量势$ \phi $和矢量势$ \vec{A} $后会有一个冗余自由度，即在

$ \vec{A}\rightarrow \vec{A}' = \vec{A} + \nabla \Lambda $

$ \phi \rightarrow \phi ' = \phi  -\frac{\partial \Lambda}{\partial t} $

    - 的规范变换下，$ \vec{E},\vec{B} $取相同的值。
    - 此时引入**洛伦茨规范（Lorenz Gauge）**，消掉这个冗余自由度：

$ \frac{1}{c^2}\frac{\partial\phi}{\partial t} + \nabla \cdot \vec{A} = 0 $

+ 此外，还应该有电荷守恒：

$ \frac{\partial \rho}{\partial t} + \nabla \cdot \vec{j} = 0 $

### 4-电流密度与4-势
#### 4-电流密度与4-势的引入
+ 在1234约定下，引入四维电流密度和四维电磁势：

$ j_\mu := \left(\vec{j},ic\rho\right) $

$ A_\mu := \left(\vec{A}, \frac{i\phi}{c}\right) $

    - 回忆：

$ \partial_\mu := \left(\nabla,\frac{1}{ic}\frac{\partial }{\partial t}\right) $

$ \square :=\partial_\mu\partial_\mu = \nabla^2-\frac{1}{c^2}\frac{\partial ^2}{\partial t^2} $

#### 电磁势微分方程的协变形式
+ 首先写出标量势满足的微分方程：

$ \nabla^2 \phi - \frac{1}{c^2}\frac{\partial^2 \phi}{\partial t^2} = -\frac{\rho}{\epsilon_0} $

    - 可以改写为：

$ \square\phi = -\frac{\rho}{\epsilon_0} = -\mu_0 c^2\rho $

$ \Rightarrow \square \left(\frac{i\phi}{c}\right) = -\mu_0 (ic\rho) $

$ \Rightarrow \square A_0 = -\mu_0j_0 $

+ 然后写出矢量势满足的微分方程：

$ \nabla^2 \vec{A} - \frac{1}{c^2}\frac{\partial^2 \vec{A} }{\partial t^2} = -\mu_0\vec{j} $

    - 对于三个分量都可以进行类似的讨论：

$ \nabla^2 A_i - \frac{1}{c^2}\frac{\partial^2 A_i  }{\partial t^2} = -\mu_0j_i ,\; i = 1,2,3  $

    - 可以进行改写：

$ \square A_i  = -\mu_0j_i ,\; i = 1,2,3  $

+ 综合上面两个式子，我们得到**电磁势微分方程的协变形式**：

$ \boxed{\square A_\mu  = -\mu_0j_\mu ,\; \mu = 1,2,3,4} $

#### 洛伦茨规范的协变形式
+ 对于洛伦茨规范进行改写：

$ 0 = \frac{1}{c^2}\frac{\partial\phi}{\partial t} + \nabla \cdot \vec{A}  = \frac{1}{ic}\frac{\partial }{\partial t}\left(\frac{i\phi}{c}\right) + \nabla \cdot \vec{A} = \partial_\mu A_\mu  $

    - 我们这就得到了**洛伦茨规范的协变形式**：

$ \boxed{ \partial_\mu A_\mu  = 0} $

#### 电荷守恒的协变形式
+ 对于电荷守恒方程进行改写：

$ 0 = \frac{\partial \rho}{\partial t} + \nabla \cdot \vec{j} = \frac{1}{ic}\frac{\partial}{\partial t} \left(ic\rho\right) + \nabla \cdot \vec{j} = \partial_\mu j_\mu $

    - 我们这就得到了**电荷守恒方程的协变形式**：

$ \boxed{ \partial_\mu j_\mu  = 0} $

#### 协变性证明
+ 首先给出一些基本的变换式：

$ S\rightarrow S' $

$ x_\mu \rightarrow x_\mu' = L_{\mu\nu} x_\nu $

$ \partial_\mu \rightarrow \partial_\mu' = L_{\mu\nu} \partial_\nu $

$ \square \rightarrow \square '  =\partial_\mu' \partial_\mu' =L_{\mu\nu}\partial_\nu L_{\mu\rho}\partial_\rho = L_{\mu\nu} L_{\mu\rho}\partial_\nu\partial_\rho = \delta_{\nu\rho}\partial_\nu\partial_\rho  = \partial_\nu\partial_\nu = \square $

+ 下面证明**电磁势微分方程的协变性**：

$ \square A_\mu  = -\mu_0j_\mu ,\; \mu = 1,2,3,4 $

    - 两侧同时乘以$ L_{\nu\mu} $并求和：

$ \square L_{\nu\mu}A_\mu  = -\mu_0L_{\nu\mu}j_\mu ,\; \mu = 1,2,3,4 $

        * 注意到：

$ A_\mu \rightarrow A_\mu' = L_{\mu\nu} A_\nu $

$ j_\mu \rightarrow j_\mu' = L_{\mu\nu} j_\nu $

$ \square \rightarrow \square '  = \square $

    - 这个时候就可以得到：

$ \square'A'_\nu  = -\mu_0j'_\nu ,\; \nu = 1,2,3,4 $

$ \Rightarrow \square'A'_\mu  = -\mu_0j'_\mu ,\; \mu = 1,2,3,4 $

    - 这就证明在$ S\rightarrow S' $系的变换下，电磁势微分方程具有协变性。
+ 下面证明**洛伦茨规范的协变性**：
    - 我们不妨从变换后的结果出发：

$  \partial_\mu' A_\mu'  = 0 $

        * 注意到：

$ \partial_\mu \rightarrow \partial_\mu' = L_{\mu\nu} \partial_\nu $

$ A_\mu \rightarrow A_\mu' = L_{\mu\nu} A_\nu $

    - 这个时候就可以得到：

$ L_{\mu\nu} \partial_\nu  L_{\mu\rho} A_\rho= 0 $

$ \Rightarrow L_{\mu\nu} L_{\mu\rho}\partial_\nu   A_\rho= 0 $

$ \Rightarrow \delta_{\nu\rho}\partial_\nu   A_\rho= 0 $

$ \Rightarrow \partial_\nu   A_\nu= 0 $

$ \Rightarrow \partial_\mu   A_\mu= 0 $

    - 这就证明在$ S\rightarrow S' $系的变换下，洛伦茨规范具有协变性。
+ 类似可以证明**电荷守恒的协变性**，实际上就是把$ A $换成$ j $：

$  \partial_\mu' j_\mu'  = 0 $

$ \Rightarrow L_{\mu\nu} \partial_\nu  L_{\mu\rho} j_\rho= 0 $

$ \Rightarrow \partial_\mu   j_\mu= 0 $

    - 这就证明在$ S\rightarrow S' $系的变换下，电荷守恒具有协变性。

### 4-势的洛伦兹变换
#### 4-势的洛伦兹正变换
+ 假设$ S' $系沿着$ x $轴正方向以速度$ v $运动，我们已知：

$ A_\mu' = L_{\mu\nu} A_\nu $

$ A_\mu := \left(\vec{A}, \frac{i\phi}{c}\right) $

$  (L_{\mu\nu}) = \begin{pmatrix}\gamma & 0 & 0 & i\beta \gamma \\ 0 & 1 & 0 & 0 \\ 0 & 0 & 1 & 0 \\ -i\beta \gamma & 0 & 0 & \gamma \end{pmatrix} $

+ 这个时候可以写出：

$ A_x' = \gamma(A_x - \frac{v\phi}{c^2}) $

$ A_y' = A_y $

$ A_z' = A_z $

$ \phi' = \gamma(\phi - vA_x) $

    - 或者引入$ \beta = v/c $，写成更加对称的形式：

$ A_x' = \gamma(A_x - \beta\frac{\phi}{c}) $

$ A_y' = A_y $

$ A_z' = A_z $

$ \frac{\phi'}{c} = \gamma(\frac{\phi}{c} - \beta A_x) $

    - 这就是**4-势的洛伦兹正变换**。

#### 4-势的洛伦兹逆变换
+ 做$ (v,A_i,\phi)\leftrightarrow (-v,A_i',\phi') $的替换，可以得到：

$ A_x = \gamma(A_x' + \frac{v\phi'}{c^2})  $

$ A_y = A_y' $

$ A_z = A_z' $

$ \phi = \gamma(\phi'+ vA_x')  $

    - 或者写成更对称的形式：

$ A_x = \gamma(A_x' + \beta\frac{\phi'}{c}) $

$ A_y = A_y' $

$ A_z = A_z' $

$ \frac{\phi}{c} = \gamma(\frac{\phi'}{c} - \beta A_x') $

    - 这就是**4-势的洛伦兹逆变换**。

### 例题：匀速运动的电荷的电磁势，不考虑推迟效应
#### 情景叙述
+ 从$ S $系来看，有一个沿着$ x $轴匀速直线运动的电荷$ q $，运动速度为$ v $，求在$ S $系中产生的电磁势。

#### 解答过程
+ 首先，构建与电荷$ q $共动的参考系$ S' $，原点选择为$ q $的位置，$ x'y'z' $轴与$ S $系的$ xyz $轴分别平行。
+ 在$ S' $系中，电荷$ q $是静止的，位于原点。
    - 那么，从$ S' $系看来，电磁势满足：

$ \phi' = \frac{1}{4\pi \epsilon_0} \frac{q}{r'} $

$ A_i' = 0 $

    - 注意，此处的$ ' $代表与$ S' $系对应，而非源空间。
+ 根据**4-势的洛伦兹逆变换**，我们可以得到$ S $系中观察到的电磁势：

$ A_x = \gamma(A_x' + \frac{v\phi'}{c^2}) = \frac{1}{4\pi \epsilon_0}\frac{v\gamma}{c^2}\frac{q}{r'} = \frac{1}{4\pi \epsilon_0}\frac{v\gamma}{c^2}\frac{q}{\sqrt{x'^2+y'^2+z'^2}} $

$ A_y = A_y' $

$ A_z = A_z' $

$ \phi = \gamma(\phi'+ vA_x') = \frac{1}{4\pi\epsilon_0} \gamma \frac{q}{r'} = \frac{1}{4\pi\epsilon_0} \gamma\frac{q}{\sqrt{x'^2+y'^2+z'^2}} $

+ 解答并没有完成，因为$ A_x,\phi $中还有还有未知的$ x',y',z' $。
+ 根据**时空的洛伦兹正变换**：

$ x^{\prime} = \gamma(x - vt) $

$ y' = y $

$ z' = z $  
$ t^{\prime} = \gamma(t - \beta x/c) $

    - 可以得到：

$ A_x = \frac{1}{4\pi \epsilon_0}\frac{v\gamma}{c^2}\frac{q}{\sqrt{\gamma^2(x - vt)^2+y^2+z^2}} $

$ A_y = A_y' $

$ A_z = A_z' $

$ \phi  = \frac{1}{4\pi\epsilon_0} \gamma\frac{q}{\sqrt{\gamma^2(x - vt)^2+y^2+z^2}} $

    - **<font style="color:#DF2A3F;">注意！这个解答过程并没有考虑到推迟效应，因此仅限于运动速度较慢、距离电荷较近的位置。</font>**

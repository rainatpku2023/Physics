### 狭义相对论的基本原理
+ **（1）相对性原理**：所有惯性参考系都是等价的，物理规律在所有惯性参考系中都具有相同的表达形式；
+ **（2）光速不变原理**：在真空中，光的传播速率相对于任何惯性系都相同（为 $ c $ ），且与光源的运动无关。

### 洛伦兹变换
+ 假设时空均匀、各向同性，建立线性坐标变换：

$ x^{\prime} = \gamma x + \delta t $ (1)

$ y^{\prime} = y $ (2)

$ z^{\prime} = z $ (3)

$ t^{\prime} = \beta x + \alpha t $ (4)

+ 对于 $ S^{\prime} $ 系中静止的点， $ dx^{\prime} = dy^{\prime} = dz^{\prime} = 0 $，此点在 $ S $ 系中的速度为 $ \vec{v} $：

$ \frac{dx}{dt} = -\frac{\delta}{\gamma} = v $ (5)

+ 类似地， $ S $ 系中静止的点 $ dx = dy = dz = 0 $，其在 $ S^{\prime} $ 系中的速度为 $ -v $（ $ S^{\prime} $ 系中坐标为 $ x^{\prime}, y^{\prime}, z^{\prime}, t^{\prime} $）：

$ \frac{dx^{\prime}}{dt^{\prime}} = \frac{\delta}{\alpha} = -v $

+ 由此可得：

$ \alpha = \gamma, $

$ \delta = -\gamma v, \quad \beta = -\eta\gamma $ (6)

+ 代入原方程消元：

$ x^{\prime} = \gamma(x - vt) $ (7)

$ y^{\prime} = y $ (8)

$ z^{\prime} = z $ (9)

$ t^{\prime} = \gamma(t - \eta x) $ (10)

+ 设 $ t^{\prime} = t = 0 $ 时， $ S, S^{\prime} $ 原点重合。此时发出一束光，由光速不变原理，在 $ S, S^{\prime} $ 系中传播分别满足：

$ x^{2} + y^{2} + z^{2} - c^{2}t^{2} = 0 $ (11)

$ x^{\prime 2} + y^{\prime 2} + z^{\prime 2} - c^{2}t^{\prime 2} = 0 $ (12)

#### 求解待定系数
+ **考虑特殊事件 1**： $ S $ 系中时刻 $ t $ 光到达点 $ (x = ct, y = 0, z = 0) $，则 $ S^{\prime} $ 系中：

$ x^{\prime} = \gamma t(c - v), \quad y^{\prime} = 0, \quad z^{\prime} = 0, \quad t^{\prime} = \gamma t(1 - \eta c) $

    - 由式 (11) 和式 (12) 的时空间隔不变性：

 $ \Rightarrow \eta = \frac{v}{c^{2}} $ (13)

+ **考虑特殊事件 2**： $ S $ 系中时刻 $ t $ 光到达点 $ (x = 0, y = ct, z = 0) $，则 $ S^{\prime} $ 系中：

$ x^{\prime} = -\gamma vt, \quad y^{\prime} = ct, \quad z^{\prime} = 0, \quad t^{\prime} = \gamma t $

+ 由式 (11) 和式 (12) 的时空间隔不变性 

$ \Rightarrow \gamma = \frac{1}{\sqrt{1 - v^{2}/c^{2}}} $ (14)

#### 洛伦兹变换标准形式
$ \begin{cases} x^{\prime} = \frac{x - vt}{\sqrt{1 - v^{2}/c^{2}}} \\ y^{\prime} = y \\ z^{\prime} = z \\ t^{\prime} = \frac{t - \frac{v}{c^{2}}x}{\sqrt{1 - v^{2}/c^{2}}} \end{cases} $ (15)

+ 令 $ \beta = \frac{v}{c} $ ， $ \gamma = \frac{1}{\sqrt{1 - \beta^{2}}} $，洛伦兹变换可简写为：

$ \begin{cases} x^{\prime} = \gamma(x - vt) = \gamma(x - \beta ct) \\ y^{\prime} = y \\ z^{\prime} = z \\ t^{\prime} = \gamma(t - \frac{\beta}{c}x) \end{cases} $

#### 附录：引入逆变四矢量
> 提示：后续章节（6.4）会补充协变、逆变四矢量及度规的概念。
>

+ 令 $ x_{0} = ct, x_{1} = x, x_{2} = y, x_{3} = z $，则洛伦兹变换可以写为四矢量形式：

$ \begin{cases} x_{0}^{\prime} = \gamma(x_{0} - \beta x_{1}) \\ x_{1}^{\prime} = \gamma(x_{1} - \beta x_{0}) \\ x_{2}^{\prime} = x_{2} \\ x_{3}^{\prime} = x_{3} \end{cases} $ (16)

+ $ S^{\prime} \rightarrow S $ 的洛伦兹逆变换（变换规律： $ v \rightarrow -v $，带撇坐标与不带撇坐标互换）：

$ \begin{cases} x_{0} = \gamma(x_{0}^{\prime} + \beta x_{1}^{\prime}) \\ x_{1} = \gamma(x_{1}^{\prime} + \beta x_{0}^{\prime}) \\ x_{2} = x_{2}^{\prime} \\ x_{3} = x_{3}^{\prime} \end{cases} $ (17)

### 相对论性速度合成
+ 设 $ S^{\prime} $ 系相对于 $ S $ 系沿 $ \hat{e}_{x} $ 方向以速度 $ \vec{v} $ 运动。
    - 由洛伦兹变换：

$ x^{\prime} = \gamma(x - vt) $ (18)  
$ t^{\prime} = \gamma(t - \beta x/c) $ (19)

    - 两边取微分：

$ dx^{\prime} = \gamma(dx - vdt) $ (20)  
$ dt^{\prime} = \gamma(dt - \beta dx/c) = \gamma(1 - \beta u_{x}/c)dt $ (21)

+ 其中 $ u_{x} = \frac{dx}{dt} $ 为 $ S $ 系中的速度分量，由此得到 $ \hat{e}_{x} $ 方向的速度合成公式：

$ u_{x}^{\prime} = \frac{dx^{\prime}}{dt^{\prime}} = \frac{u_{x} - v}{1 - \beta u_{x}/c} $ (22)

+ 同理，垂直于运动方向的 $ \hat{e}_{y} $ 和 $ \hat{e}_{z} $ 方向的速度合成公式为：

$ u_{y}^{\prime} = \frac{dy^{\prime}}{dt^{\prime}} = \frac{u_{y}}{\gamma(1 - \beta u_{x}/c)} $ (23)

$ u_{z}^{\prime} = \frac{dz^{\prime}}{dt^{\prime}} = \frac{u_{z}}{\gamma(1 - \beta u_{x}/c)} $ (24)

### 速度合成的矢量形式
#### 正变换
+ 将三个方向的结果按平行和垂直于相对运动速度 $ \vec{v} $ 的分量合写为矢量形式：

$ u_{||}^{\prime} = \frac{u_{||} - v}{1 - \vec{\beta} \cdot \vec{u}/c}, \quad \vec{u}_{\perp}^{\prime} = \frac{\vec{u}_{\perp}}{\gamma(1 - \vec{\beta} \cdot \vec{u}/c)} $ (25)

+ 其中 $ \vec{\beta} = \frac{\vec{v}}{c} $， $ \gamma = \frac{1}{\sqrt{1 - \beta^{2}}} $。

#### 逆变换
$ u_{||} = \frac{u_{||}^{\prime} + v}{1 + \vec{\beta} \cdot \vec{u}^{\prime}/c}, \quad \vec{u}_{\perp} = \frac{\vec{u}_{\perp}^{\prime}}{\gamma(1 + \vec{\beta} \cdot \vec{u}^{\prime}/c)} $ (26)

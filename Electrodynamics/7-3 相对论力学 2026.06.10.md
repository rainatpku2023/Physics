### 4-力
#### 4-力的引入
+ 首先回顾非相对论性的牛顿第二定律：

$ \vec{F} = \frac{d}{dt}(m_0 \vec{v}) $

+ **修改成相对论形式的两个原则：**
    - **满足相对性原理，在洛伦兹变换下方程协变。**
    - **在低速情况**$ v\ll c $**，即牛顿近似下，回到非相对论的形式。**
+ 回顾：4-速度的定义为：

$ U_\mu := \frac{dx_\mu}{d\tau} = \frac{dt}{d\tau} (\vec{v,ic}) = \gamma (\vec{v},ic) $

+ 我们希望定义4-力可以满足：

$ F_\mu = \frac{dP_\mu}{d\tau} = \frac{d}{d\tau}(m_0U_{\mu}) $

+ 定义**4-力**：

$ \boxed{F_{\mu} := \int f_{\mu}(\gamma dV) = \gamma \int f_{\mu}dV = \gamma(\vec{F},\frac{i\tilde P}{c})} $

    - 其中积分体元写为$ \gamma dV $是因为$ \gamma dV $才是洛伦兹标量。由于尺缩效应存在，$ dV $并非不变量。
    - **<font style="color:#DF2A3F;">特别要注意前面的</font>**$ \gamma $**<font style="color:#DF2A3F;">因子。</font>**
    - $ \tilde{P} $代表功率，它与功率密度$ \omega $的关系为：

$ \tilde P := \int \omega dV $

#### 4-力与4-力密度的关系
#### 协变形式的牛顿第二定律
+ 协变形式的牛顿第二定律为：

$ F_\mu = \frac{dP_\mu}{d\tau} = \frac{d}{d\tau}(m_0U_{\mu}) $

    - 其中：

$ U_{\mu} = \gamma (\vec{v},ic) $

$ P_{\mu} = \gamma (m_0 \vec{v},im_0 c) $

+ <font style="color:#8A8F8D;">实际上，之后会这样引入4-动量，并进行这样的改写：</font>

$ P_{\mu} = (\gamma m_0 \vec{v},i\gamma m_0 c) = (\gamma m_0 \vec{v},i\gamma m_0 c^2/c)  = (\vec{p},iE/c)  $

    - <font style="color:#8A8F8D;">不过这是后话。</font>
+ 考察这个协变形式牛顿第二定律的**空间分量**：

$ F_i = \frac{dP_i}{d\tau} = \frac{d}{d\tau}(m_0U_{i}),\; i = 1,2,3 $

$ \Rightarrow \gamma F_i = \frac{d}{d\tau}(m_0 \frac{dx_i}{d\tau})=\frac{dt}{d\tau}\frac{d}{dt}(m_0 \frac{dt}{d\tau}\frac{dx_i}{dt}) = \gamma \frac{d}{dt}(\gamma m_0 v_i) $

$ \Rightarrow F_i = \frac{d}{dt}(\gamma m_0 v_i) $

$ \boxed{\vec{F} = \frac{d}{dt}(\gamma m_0 \vec{v})} $

    - 再考察**时间分量**：

$ \gamma\frac{i\tilde P}{c} = \frac{dP_4}{d\tau} = \frac{d}{d\tau}(m_0U_4)  $

$ RHS = \frac{dt}{d\tau}\frac{d}{dt}(m_0 \frac{dx_4}{d\tau}) = \frac{dt}{d\tau}\frac{d}{dt}(m_0ic \frac{dt}{d\tau}) = i\gamma \frac{d}{dt}(\gamma m_0c) $

$ \Rightarrow \tilde{P} = c\frac{d}{dt}(\gamma m_0 c) = \frac{d}{dt}(\gamma m_0 c^2) $

$ \boxed{\tilde{P} = \frac{d}{dt}(\gamma m_0 c^2)} $

#### 非相对论极限
+ $ v\ll c $非相对论极限下，可以对于洛伦兹因子$ \gamma $进行泰勒展开：

$ \gamma = \left(1-\frac{v^2}{c^2}\right)^{-1/2} = 1+\frac{1}{2}\frac{v^2}{c^2}+\cdots $

    - 相应地：

$ \vec{F} = \frac{d}{dt}(\gamma m_0 \vec{v}) \approx \frac{d}{dt}(m_0 \vec{v}) $

$ \tilde{P} = \frac{d}{dt}(\gamma m_0 c^2) \approx  \frac{d}{dt}\left[(1+\frac{1}{2}\frac{v^2}{c^2}m_0c^2)\right] = \frac{d}{dt}\left(\frac{1}{2}m_0v^2\right) $

### 静止质量、动质量与质能关系
+ 之前我们推出：

$ F_{\mu} = \gamma(\vec{F},\frac{i\tilde P}{c}) $

$ \vec{F} = \frac{d}{dt}(\gamma m_0 \vec{v}) $

$ \tilde{P} = \frac{d}{dt}(\gamma m_0 c^2) $

    - 由此，我们可以定义动质量$ m $：

$ m = \frac{m_0}{\sqrt{1-v^2/c^2}} $

+ 总功率：

$ \tilde{P} = \frac{d}{dt} (\gamma m_0 c^2) = \frac{d}{dt}(mc^2) = \frac{dE}{dt} $

+ 由此引入质能关系：

$ E = mc^2 = \frac{m_0 c^2}{\sqrt{1-v^2/c^2}} $

### 4-动量
#### 4-动量的引入
+ 定义**4-动量**：

$ P_{\mu}:= m_0 U_{\mu} = m_0\gamma (\vec{v},ic) = (\vec{p},\frac{iE}{c}) $

+ 由此可以提取出：

$ \vec{p} = \gamma m_0 \vec{v} = \frac{m_0 \vec{v}}{\sqrt{1-v^2/c^2}} = m \vec{v} $

$ E = \gamma m_0 c^2 = mc^2 $

    - 其中定义了**动质量**$ m:=\gamma m_0 $。
+ 根据这些式子，可以发现：

$ \vec{F} = \frac{d\vec{p}}{dt} $

$ \tilde{P} = \frac{dE}{dt} $

    - 这与非相对论力学相互兼容，保证了逻辑体系可以在低速极限下退回非相对论性形式。

#### 能量和动量的关系
+ **4-动量**：

$ P_{\mu}:= m_0 U_{\mu} = m_0\gamma (\vec{v},ic) = (\vec{p},\frac{iE}{c}) $

+ 可以构造一个洛伦兹不变量：

$ P_{\mu}P_{\mu} = \vec{p}\cdot \vec{p} + \frac{iE}{c}\cdot \frac{iE}{c} = p^2 -\frac{E^2}{c^2} = \gamma^2 m_0^2 v^2-\gamma^2 m_0^2 c^4  = -m_0^2 c^2 $

+ 还可以看出3-动量和能量的关系：

$ E = \sqrt{m_0^2 c^4 + p^2 c^2} $

#### 4-动量守恒
+ 如果体系受到的4-力的总和为零，那么体系的4-动量守恒。

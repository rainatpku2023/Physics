### 不变间隔
在狭义相对论中，两事件的时空间隔在不同的惯性参考系中具有不变量的形式。

对于两个时空事件，在 $ S $ 系中的时空间隔为：

$ \Delta s^{2} = c^{2}(t_{2} - t_{1})^{2} - (\vec{x}_{2} - \vec{x}_{1})^{2} $

在 $ S^{\prime} $ 系中的时空间隔为：

$ \Delta s^{\prime 2} = c^{2}(t_{2}^{\prime} - t_{1}^{\prime})^{2} - (\vec{x}_{2}^{\prime} - \vec{x}_{1}^{\prime})^{2} $

由洛伦兹变换可推导得时空间隔的不变性：

$ \Delta s^{2} = \Delta s^{\prime 2} $

### 光锥
#### 世界线与时空间隔
+ **粒子的世界线**：假设一个粒子在时间 $ t = 0 $ 时位于坐标原点。它随时间演化的轨迹在四维时空中会描述出一条曲线，称为这个粒子的**世界线**。
+ **粒子与原点之间的不变间隔**：

$ s^{2} = c^{2}t^{2} - \vec{x}^{2} $

#### 时空区域的划分

闵氏时空中任意一点可以按照它与原点之间的不变间隔分为三类，所有类光的点在四维闵氏时空中构成了**光锥**（Light Cone）：

| 间隔类型 | 数学条件 | 物理意义 |
| :--- | :--- | :--- |
| **类光间隔** |  $ s^{2} = 0 \iff |\vec{x}| = ct $ |  两事件由光波联系，光子的世界线就在光锥面上。   |
| **类时间隔** |  $ s^{2} > 0 \iff |\vec{x}| < ct $ |  两事件由慢于光速的相互作用联系（图中白色区域）。   |
| **类空间隔** |  $ s^{2} < 0 \iff |\vec{x}| > ct $ |  两事件只有超光速相互作用才能联系（图中蓝色区域）。   |


> **重要结论**：任何静止质量不为零的粒子的世界线都不会落入类空的区域，因为粒子运动的速度不可能大于光速。

### 同时的相对性
在车厢参考系（动系）中，观察者测得两束光同时到达车厢两端；而在地面参考系（静系）中，由于车厢向前运动，观察者测得两束光先后到达。这是光速不变假设的直接后果。

#### 数学定量分析
对于 $ S $ 系中的两个不同事件 $ (t_{1}, x_{1}) $ 和 $ (t_{2}, x_{2}) $，利用洛伦兹变换转换到 $ S^{\prime} $ 系中：

$ t_{1}^{\prime} = \gamma(t_{1} - vx_{1}/c^{2}) $  
$ t_{2}^{\prime} = \gamma(t_{2} - vx_{2}/c^{2}) $

两事件在 $ S^{\prime} $ 系中的时间间隔为：

$ t_{2}^{\prime} - t_{1}^{\prime} = \gamma \left[ (t_{2} - t_{1}) - \frac{v(x_{2} - x_{1})}{c^{2}} \right] $

**结论**：如果 $ S $ 系中两事件同时发生（即 $ t_{2} = t_{1} $），则在 $ S^{\prime} $ 系中的时间间隔为：

  
$ t_{2}^{\prime} - t_{1}^{\prime} = -\frac{\gamma v(x_{2} - x_{1})}{c^{2}} $

  
这表明同时具有相对性。**只有在相同地点、相同时间发生的两个事件，在其他所有惯性参考系中才是同时的。**

### 空间距离的相对性
由洛伦兹变换， $ S^{\prime} $ 系中两事件的空间相对距离为：

$ x_{2}^{\prime} - x_{1}^{\prime} = \gamma \left[ (x_{2} - x_{1}) - v(t_{2} - t_{1}) \right] $

**结论**：即便两事件在 $ S $ 系中同时发生（ $ t_{2} = t_{1} $），它们在 $ S^{\prime} $ 系中的空间距离也会改变。即空间距离同样不具有绝对不变性。

### 动钟变缓
假设 $ S^{\prime} $ 系中两事件发生在**相同地点**（即 $ x_{2}^{\prime} = x_{1}^{\prime} $），事件的时间间隔为 $ \Delta t^{\prime} = t_{2}^{\prime} - t_{1}^{\prime} \ge 0 $。

$ S^{\prime} $ 系相对于 $ S $ 系沿 $ x $ 轴以速度 $ v $ 运动，在 $ S $ 系中观测这两事件的时间间隔 $ \Delta t $：

$ \Delta t = t_{2} - t_{1} = \gamma(t_{2}^{\prime} - t_{1}^{\prime}) = \gamma \Delta t^{\prime} $

> **注意**：运动时钟变慢是**相互的**，即两个惯性参考系都认为固定在对方参考系中的时钟比自己的时钟走得慢。
>

>
> <font style="color:#DF2A3F;">设 </font>$ S $<font style="color:#DF2A3F;"> 系中两事件发生在</font>**<font style="color:#DF2A3F;">相同地点</font>**<font style="color:#DF2A3F;">（即 </font>$ x_{2} = x_{1} $<font style="color:#DF2A3F;">），事件的时间间隔为 </font>$ \Delta t = t_{2} - t_{1} \ge 0 $<font style="color:#DF2A3F;">。</font>
>
> $ S $<font style="color:#DF2A3F;"> 系相对于 </font>$ S' $<font style="color:#DF2A3F;"> 系沿 </font>$ x $<font style="color:#DF2A3F;"> 轴以速度 </font>$ -v $<font style="color:#DF2A3F;"> 运动，在 </font>$ S' $<font style="color:#DF2A3F;"> 系中观测这两事件的时间间隔 </font>$ \Delta t' $<font style="color:#DF2A3F;">：</font>
>
> $ \Delta t' = t_{2}' - t_{1}' = \gamma(t_{2} - t_{1}) = \gamma \Delta t $

### 动尺缩短
设 $ S^{\prime} $ 系相对 $ S $ 系沿 $ x $ 轴以速度 $ v $ 运动。在 $ S^{\prime} $ 系中测量静止尺子的两端（满足 $ t_{2}^{\prime} = t_{1}^{\prime} $），得到其固有长度（静止长度）为 $ L_{0} = x_{2}^{\prime} - x_{1}^{\prime} $。

根据洛伦兹变换，在 $ S $ 系中**同时**（ $ t_{2} = t_{1} $）测量该尺子的长度 $ L = x_{2} - x_{1} $：

$ x_{2}^{\prime} - x_{1}^{\prime} = \gamma \left[ (x_{2} - x_{1}) - v(t_{2} - t_{1}) \right] = \gamma (x_{2} - x_{1}) $

从而得到动尺缩短公式：

$ L = \frac{L_{0}}{\gamma} $

> **本质说明**：所谓的“动尺缩短”或“动钟变缓”效应，完全是一种**运动学的测量效应**。构成尺子或钟表本身的物质结构并没有发生任何物理或化学上的变化，它是时空相对论效应的直接体现。
>
> <font style="color:#DF2A3F;">因为在</font>$ S' $<font style="color:#DF2A3F;">系测量固定在</font>$ S $<font style="color:#DF2A3F;">系上的尺子时，要求</font>$ t_{2}^{\prime} = t_{1}^{\prime} $<font style="color:#DF2A3F;">而非</font>$ t_{1} = t_{2} $<font style="color:#DF2A3F;">。</font>
>

**<font style="color:#DF2A3F;">注意：钟慢尺缩都是二级结论，强烈依赖于假设（同时测量的定义，相同位置的定义）。在实际解决问题时从洛伦兹变换出发更加靠谱，不容易出错。</font>**

### 因果律
因果性是指事件发生的时间顺序：在前面发生的事件（原因）有可能引起后面发生的事件（结果），而反过来则是绝对不可能的。

设事件 1 和事件 2 在 $ S $ 系中的坐标为 $ (t_{1}, x_{1}) $ 和 $ (t_{2}, x_{2}) $，在 $ S^{\prime} $ 系中为 $ (t_{1}^{\prime}, x_{1}^{\prime}) $ 和 $ (t_{2}^{\prime}, x_{2}^{\prime}) $。  
在 $ S $ 系中，事件 1 为因，事件 2 为果，即满足： $ t_{1} < t_{2} $（ $ \Delta t = t_{2} - t_{1} > 0 $）。

要在 $ S^{\prime} $ 系中保证因果律不被破坏，必须要求 $ t_{2}^{\prime} > t_{1}^{\prime} $。根据洛伦兹变换：

$ t_{2}^{\prime} - t_{1}^{\prime} = \gamma \left[ (t_{2} - t_{1}) - \frac{v(x_{2} - x_{1})}{c^{2}} \right] > 0 $

由此可推导出：

$ (t_{2} - t_{1}) - \frac{\beta(x_{2} - x_{1})}{c} > 0 $

分类讨论：

+ 若 $ v > 0, x_{2} - x_{1} < 0 $ 或 $ v < 0, x_{2} - x_{1} > 0 $ 时，上式自然成立。
+ 若 $ v > 0, x_{2} - x_{1} > 0 $ 或 $ v < 0, x_{2} - x_{1} < 0 $ 时，要求：

$ t_{2} - t_{1} - \frac{|v||x_{2} - x_{1}|}{c^{2}} > 0 $

令两事件的信息传递速度为 $ u = \frac{x_{2} - x_{1}}{t_{2} - t_{1}} $，代入上式可得：

$ uv < c^{2} $

**最终结论**：由于现实中任何信号或物质的运动速度、信息传递速度均不能超过光速（即 $ u \le c $ 且 $ v < c $），因此 $ uv < c^{2} $ 必然成立。这说明**洛伦兹变换不会破坏因果律**。

### 束缚态微扰论
#### 微扰论
+ 定态薛定谔方程的一般形式为：

$ \hat{H}\ket{\psi} = E\ket{\psi} $

+ 此方程的求解一般比较困难，假设可做如下的分解：

$ \hat{H} = \hat{H}_0 +\hat{H}' $

    - 如果$ \hat{H}_0 $对应的定态薛定谔方程的本征值和本征函数比较容易解出，同时$ \hat{H}' $的影响较小（称为“微扰”），那么可以首先写出$ \hat{H}_0 $本征值问题的解，然后将$ \hat{H}' $的影响逐级考虑进去，然后再根据需要选取近似的级数。

#### 微扰论的一般推导
+ 定态薛定谔方程：

$ \hat{H}\ket{\psi} = E\ket{\psi} $

    - 其中$ \hat{H} = \hat{H}_0 +\hat{H}' $。
+ 假设最终$ \hat{H} $本征值问题的本征值（能量）和本征函数（波函数）可以写成逐级展开的形式：

$ \ket{\psi}= \ket{\psi^{(0)}}+ \ket{\psi^{(1)}}+ \ket{\psi^{(2)}}+\cdots $

$ E = E^{(0)}+E^{(1)}+E^{(2)} +\cdots $

    - 同时约定波函数的各级高级近似解与零级近似解都正交，即：

$ \braket{\psi^{(0)}|\psi^{(s)}},\; s = 1,2,3... $

        * 我们之后会用到这个结论。根据微扰论求出高级波函数后也要验证这个假设是否成立。如果成立问题就解决了，如果不成立则需要选取一组新的零级近似解，然后重新尝试。
    - 以及零级近似解定义为：

$ \hat{H}_0\ket{\psi^{(0)}} = E^{(0)}\ket{\psi^{(0)}} $

+ 将逐级展开的波函数和能量本征值代入定态薛定谔方程：

$ \left(\hat{H}_0 +\hat{H}'\right)\left(\ket{\psi^{(0)}}+ \ket{\psi^{(1)}}+ \ket{\psi^{(2)}}+\cdots\right) =\left(E^{(0)}+E^{(1)}+E^{(2)} +\cdots\right)\left(\ket{\psi^{(0)}}+ \ket{\psi^{(1)}}+ \ket{\psi^{(2)}}+\cdots\right) $

+ 然后逐级比较：
    - $ \hat{H}' $视为比$ \hat{H}_0 $高一级的小量
    - $ \ket{\psi^{(n+1)}} $视为比$ \ket{\psi^{(n)}} $高一级的小量
    - $ E^{(n+1) } $视为比$ E^{(n) } $高一级的小量
    - 得到：
        * 零级近似：$ \hat{H}\ket{\psi^{(0)}} = E^{(0)}\ket{\psi^{(0)}} $
        * 一级近似：$ \hat{H}\ket{\psi^{(1)}}+\hat{H}'\ket{\psi^{(0)}} = E^{(0)}\ket{\psi^{(1)}}+E^{(1)}\ket{\psi^{(0)}} $
        * 二级近似：$ \hat{H}\ket{\psi^{(2)}}+\hat{H}'\ket{\psi^{(1)}} = E^{(0)}\ket{\psi^{(2)}}+E^{(1)}\ket{\psi^{(1)}}+E^{(2)}\ket{\psi^{(0)}} $
        * 三级近似：$ \hat{H}\ket{\psi^{(3)}}+\hat{H}'\ket{\psi^{(2)}} = E^{(0)}\ket{\psi^{(3)}}+E^{(1)}\ket{\psi^{(2)}}+E^{(2)}\ket{\psi^{(1)}}+E^{(3)}\ket{\psi^{(0)}} $
    - 整理后，得到：
        * 零级近似：$ \left(\hat{H}_0-E^{(0)}\right)\ket{\psi^{(0)}} = 0 $
        * 一级近似：$ \left(\hat{H}_0-E^{(0)}\right)\ket{\psi^{(1)}} = \left(E^{(1)}-\hat{H}'\right)\ket{\psi^{(0)}} $
        * 二级近似：$ \left(\hat{H}_0-E^{(0)}\right)\ket{\psi^{(2)}} = \left(E^{(1)}-\hat{H}'\right)\ket{\psi^{(1)}}+E^{(2)}\ket{\psi^{(0)}} $
        * 三级近似：$ \left(\hat{H}_0-E^{(0)}\right)\ket{\psi^{(3)}} = \left(E^{(1)}-\hat{H}'\right)\ket{\psi^{(2)}}+E^{(2)}\ket{\psi^{(1)}}+E^{(3)}\ket{\psi^{(0)}} $
        * s级近似：

$ \left(\hat{H}_0-E^{(0)}\right)\ket{\psi^{(s)}} = \left(E^{(1)}-\hat{H}'\right)\ket{\psi^{(s-1)}}+E^{(2)}\ket{\psi^{(s-2)}}+E^{(3)}\ket{\psi^{(s-3)}}+\cdots +E^{(s)}\ket{\psi^{(0)}} $



    - 对于$ s $级近似方程同时左乘以$ \bra{\psi^{(0)}} $，并代入假设$ \braket{\psi^{(0)}|\psi^{(s)}},\; s = 1,2,3... $：

$ LHS = \bra{\psi^{(0)}}\hat{H}_0-E^{(0)}\ket{\psi^{(s)}} =\bra{\psi^{(0)}}E^{(0)}-E^{(0)}\ket{\psi^{(s)}} =0 $

        * 其中用到了$ \hat{H}_0\ket{\psi^{(0)}} = E^{(0)}\ket{\psi^{(0)}} $。

$ RHS = \bra{\psi^{(0)}}\left(E^{(1)}-\hat{H}'\right)\ket{\psi^{(s)}}+\bra{\psi^{(0)}}E^{(2)}\ket{\psi^{(s-1)}}+\bra{\psi^{(0)}}E^{(3)}\ket{\psi^{(s-2)}} + \cdots +\bra{\psi^{(0)}}E^{(s)}\ket{\psi^{(0)}} $

$ =-\bra{\psi^{(0)}}\hat{H}'\ket{\psi^{(s)}} + \bra{\psi^{(0)}}E^{(s)}\ket{\psi^{(0)}}
= -\bra{\psi^{(0)}}\hat{H}'\ket{\psi^{(s-1)}} + E^{(s)} $

        * 其中用到了$ \braket{\psi^{(0)}|\psi^{(s)}},\; s = 1,2,3... $。
    - 得到：

$ 0=-\bra{\psi^{(0)}}\hat{H}'\ket{\psi^{(s-1)}} + E^{(s)}  $

    - 即：

$ \boxed{E^{(s)} =\bra{\psi^{(0)}}\hat{H}'\ket{\psi^{(s-1)}},\; s = 1,2,3...} $

#### 非简并态微扰论
+ 假设能级不存在简并，此时可以选取波函数组$ \{\ket{\psi^{(0)}_k}\} $，满足：

$ \hat{H}_0\ket{\psi^{(0)}_k} = E_k^{(0)}\ket{\psi^{(0)}_k} $

$ E_k^{(0)} \neq  E_m^{(0)},k\neq m $

##### 一级近似
+ 因为零级波函数是正交归一的完备基矢，所以一级近似波函数可以用它们来展开：

$ \ket{\psi^{(1)}} = \sum_{n}a_n^{(1)}\ket{\psi_n^{(0)}} $

    - 其中$ a_n^{(1)} $为叠加系数，求一级微扰波函数的问题就转化为了求叠加系数。
+ 根据：

$ \left(\hat{H}_0-E^{(0)}\right)\ket{\psi^{(1)}} = \left(E^{(1)}-\hat{H}'\right)\ket{\psi^{(0)}} $

    - 得到第$ k $个本征波函数的一级微扰近似的表达式：

$ \left(\hat{H}_0-E_k^{(0)}\right)\ket{\psi_k^{(1)}} = \left(E_k^{(1)}-\hat{H}'\right)\ket{\psi_k^{(0)}} $

    - 将一级近似波函数用零级波函数展开的形式代入：

$ \left(\hat{H}_0-E_k^{(0)}\right)\sum_{n}a_{nk}^{(1)}\ket{\psi_n^{(0)}} = \left(E_k^{(1)}-\hat{H}'\right)\ket{\psi_k^{(0)}} $

    - 两边同时左乘$ \bra{\psi_m^{(0)}} $：

$ LHS = \bra{\psi_m^{(0)}}\left(\hat{H}_0-E_k^{(0)}\right)\sum_{n}a_{nk}^{(1)}\ket{\psi_n^{(0)}} = \sum_{n}a_{nk}^{(1)}\bra{\psi_m^{(0)}}\left(\hat{H}_0-E_k^{(0)}\right)\ket{\psi_n^{(0)}} $

$ = \sum_{n}a_{nk}^{(1)} \left(E_m^{(0)}-E_k^{(0)}\right)\braket{\psi_m^{(0)}|\psi_n^{(0)}} = \sum_{n}a_{nk}^{(1)} \left(E_m^{(0)}-E_k^{(0)}\right)\delta_{mn} $

$ = a_{mk}^{(1)} \left(E_m^{(0)}-E_k^{(0)}\right) $

$ RHS = \bra{\psi_m^{(0)}}\left(E_k^{(1)}-\hat{H}'\right)\ket{\psi_k^{(0)}} =  E_k^{(1)}\braket{\psi_m^{(0)}|\psi_k^{(0)}}- \bra{\psi_m^{(0)}}\hat{H}'\ket{\psi_k^{(0)}} $

$ = E_k^{(1)}\delta_{mk}- H'_{mk} $

$ \boxed{H_{mk}':=\bra{\psi_m^{(0)}}\hat{H}'\ket{\psi_k^{(0)}}} $

    - 即：

$ a_{mk}^{(1)} \left(E_m^{(0)}-E_k^{(0)}\right) = E_k^{(1)}\delta_{mk}- H'_{mk} $

+ 对于$ m = k $：

$ 0= E_m^{(1)}- H'_{mm} $

    - 即：

$ \boxed{ E_m^{(1)}=  H'_{mm} =\bra{\psi_m^{(0)}}\hat{H}'\ket{\psi_m^{(0)}},\;m=k} $

+ 对于$ m\neq k $：

$ a_{mk}^{(1)} \left(E_m^{(0)}-E_k^{(0)}\right) =- H'_{mk} $

    - 即：

$ \boxed{a_{mk}^{(1)}  =\frac{H'_{mk}}{E_k^{(0)}-E_m^{(0)}} = \frac{\bra{\psi_m^{(0)}}\hat{H}'\ket{\psi_k^{(0)}}}{E_k^{(0)}-E_m^{(0)}},\; m\neq k} $

+ 综上，本征值和本征函数的一级近似是：

$ E_k = E_k^{(0)}+E_k^{(1)} =  E_k^{(0)} +  H_{kk}' $

$ \ket{\psi_k} = \ket{\psi_k^{(0)}} + \ket{\psi_k^{(1)}}  = \ket{\psi_k^{(0)}} + \sum_{n\neq k}\frac{H'_{nk}}{E_k^{(0)}-E_n^{(0)}}  \ket{\psi_n^{(0)}} $

##### 二级近似
+ 根据：

$ E^{(s)} =\bra{\psi^{(0)}}\hat{H}'\ket{\psi^{(s-1)}},\; s = 1,2,3... $

    - 有：

$ E_k^{(2)} =\bra{\psi^{(0)}_k}\hat{H}'\ket{\psi^{(1)}_k} $

+ 之前我们求出：

$  \ket{\psi_k^{(1)}}  =\sum_{n\neq k}\frac{H'_{nk}}{E_k^{(0)}-E_n^{(0)}}  \ket{\psi_n^{(0)}} $

    - 代入得到：

$ E_k^{(2)} =\bra{\psi^{(0)}_k}\hat{H}'\sum_{n\neq k}\frac{H'_{nk}}{E_k^{(0)}-E_n^{(0)}}  \ket{\psi_n^{(0)}} =\sum_{n\neq k}\frac{H'_{nk}}{E_k^{(0)}-E_n^{(0)}}  \bra{\psi^{(0)}_k}\hat{H}'\ket{\psi_n^{(0)}} $

$ = \sum_{n\neq k}\frac{H'_{nk}}{E_k^{(0)}-E_n^{(0)}}  H'_{kn} = \sum_{n\neq k}\frac{H'_{nk}}{E_k^{(0)}-E_n^{(0)}}  H'^*_{nk} = \sum_{n\neq k}\frac{|H'_{nk}|^2}{E_k^{(0)}-E_n^{(0)}} $

    - 即：

$ \boxed{E_k^{(2)} = \sum_{n\neq k}\frac{|H'_{nk}|^2}{E_k^{(0)}-E_n^{(0)}}} $

+ 本征值的二级近似是：

$ E_k = E_k^{(0)}+E_k^{(1)}+E_k^{(2)} =  E_k^{(0)} +  H_{kk}'+ \sum_{n\neq k}\frac{|H'_{nk}|^2}{E_k^{(0)}-E_n^{(0)}} $

##### 非简并态逐级展开的收敛性要求
+ 非简并态微扰论逐级展开要求：

$ \left|\frac{H'_{nk}}{E_k^{(0)}-E_n^{(0)}}\right| \ll 1, \; \forall n \neq k $

+ 基本思路：
    - 根据旧的本征函数基重新构造新本征函数基，使微扰哈密顿量矩阵元成为对角矩阵。
    - 此时增加微扰后新本征函数基对应的能量就会发生退简并。

##### 曾谨言书修改
+ 假设在不考虑微扰时，体系处于某个 $ f_k $ 重简并的能级 $ E_k^{(0)} $，即：

$ E^{(0)} = E_k^{(0)} $

+ 与非简并态不同的是，此时的零级波函数尚不能完全确定。根据线性空间的基底展开理论，其一般形式必然写为简并子空间基底 $ |\phi_{k\mu}^{(0)}\rangle $ 的线性组合。引入爱因斯坦求和约定（一上一下相同指标自动求和），通用零级波函数表达式为：

$ |\psi_{k}^{(0)}\rangle = a^\mu |\phi_{k\mu}^{(0)}\rangle $

+ 其中，$ \mu = 1, 2, \cdots, f_k $ 为求和哑指标，而能级标签 $ k $ 为未参与求和的自由指标。
+ 将通用展开式代入一级微扰方程中，可得：

$ (\hat H_0 - E_k^{(0)}) |\psi_k^{(1)}\rangle = (E^{(1)} - \hat H') |\psi_k^{(0)}\rangle = (E^{(1)} - \hat H') \left( a^\mu |\phi_{k\mu}^{(0)}\rangle \right) $

+ 为了求解系数 $ a^\mu $，我们在方程两边左乘对偶空间的左矢基底 $ \langle\phi_{k}^{(0)\nu}| $（其中 $ \nu $ 为处于逆变位置的自由指标）。利用简并子空间内部基底的正交归一性定义度规张量：

$ \langle\phi_{k}^{(0)\nu} | \phi_{k\mu}^{(0)}\rangle = \delta^\nu_\mu $

+ 同时，定义微扰算符 $ \hat H' $ 在该简并子空间下的混合张量矩阵元为：

$ \hat H'^\nu_\mu = \langle\phi_{k}^{(0)\nu} | \hat H' | \phi_{k\mu}^{(0)}\rangle $

+ 由于 $ (\hat H_0 - E_k^{(0)}) $ 作用在左矢上为 $ 0 $，方程左边项消去。移项并提取共有系数 $ a^\mu $ 后，得到确定展开系数 $ a^\mu $ 所满足的齐次线性方程组：

$ (\hat H'^\nu_\mu - E^{(1)}\delta^\nu_\mu) a^\mu = 0 $

+ 该齐次线性方程组有非平庸解（ $ a^\mu \neq 0 $ ）的充要条件是其混合张量系数矩阵的行列式为零，即满足久期方程（secular equation）：

$ \det | \hat H'^\nu_\mu - E^{(1)}\delta^\nu_\mu | = 0 $

+ 根据微扰算符 $ H' $ 的厄米性，久期方程必然有 $ f_k $ 个实根，我们用协变自由指标 $ \alpha $ 来区分不同的根，记为 $ E_{k\alpha}^{(1)} $（ $ \alpha = 1, 2, \cdots, f_k $ ）。
+ 将每一个确定的能量修正根 $ E_{k\alpha}^{(1)} $ 分别代回齐次方程组中，即可求得与之对应的一组特定组合系数，记为 $ a^\mu_\alpha $。其中指标 $ \mu $ 决定基底的线性叠加，指标 $ \alpha $ 标记该系数属于第 $ \alpha $ 个解。
+ 由此，我们便可以构造出能够完全解除简并的、处于该能级下的**正确零级波函数**：

$ |\psi_{k\alpha}^{(0)}\rangle = a^\mu_\alpha |\phi_{k\mu}^{(0)}\rangle, \quad \alpha = 1, 2, \cdots, f_k $

+ 其相应的、准确到一级微扰修正的系统总能量本征值为：

$ E_{k\alpha} = E_k^{(0)} + E_{k\alpha}^{(1)} $

+ 如 $ f_k $ 个根 $ E_{k\alpha}^{(1)} $ 互不相等，则原有的 $ f_k $ 重简并能级 $ E_k^{(0)} $ 将完全解除简并，分裂为 $ f_k $ 条独立的能级，所对应的正确零级波函数与能量本征值完全由上式给出。但若 $ E_{k\alpha}^{(1)} $ 仍有部分重根，则能级简并尚未完全解除，凡是未完全解除简并的能量本征值，其相应的正确零级波函数仍具有一定的不确定性。



### 散射态微扰论
#### 散射态的描述
##### 散射截面
+ 在散射问题中，人们关注的不是能量本征值（它可以连续变化），而是散射粒子的角分布。
+ 粒子的大小远远小于仪器的大小，所以可以认为是$ r\rightarrow \infin $的结果，考察的是渐近行为。
+ 定义：
    - 入射流密度$ j_i $：单位时间内穿过单位面积的粒子数。
    - 散射截面$ \sigma $：单位时间内有$ dn $个粒子沿着$ (\theta,\varphi) $方向的立体角$ d\Omega $出射：

$ \sigma(\theta,\varphi) = \frac{1}{j_i}\left(\frac{dn}{d\Omega}\right) $

        * 显然散射截面的量纲是面积。
    - 纵截面$ \sigma_t $：散射截面关于全$ 4\pi $空间角的积分：

$ \sigma_t = \int \sigma(\theta,\varphi)d\Omega  = \int_{0}^{2\pi}d\varphi \int_{0}^{\pi}\sin\theta d\theta \sigma(\theta,\varphi) $

##### 波函数
+ 在量子力学的散射实验中，一般假设：
    - 弹性散射：入射粒子和靶粒子内部状态不改变，整体不损失动能。
    - 有限的力程：在$ |\vec{r}|>a $的区域内，$ V(\vec{r}) = 0 $，即粒子是自由的。
    - 近似认为入射平面波，出射球面波。
+ 因此，波函数在$ r\rightarrow \infin $时的渐进行为是：

$ \psi \rightarrow e^{ikz} +f(\theta)\frac{e^{ikr}}{r} $

    - 其中第一项为入射波，第二项为散射波。

##### 散射截面计算
+ 入射波对应的粒子流密度为：

$ j_i = -\frac{i\hbar}{2m}\left(\psi_i^* \nabla \psi_i - \psi_i \nabla \psi_i^*\right) $

$ =\frac{i\hbar}{2\mu} \left[e^{ikz} \frac{d}{dz} \left(e^{-ikz}\right) - c.c.\right] $

$ =\frac{\hbar k}{\mu} $

+ 散射波对应的径向散射流密度为：

$ j_s = -\frac{i\hbar}{2m}\left(\psi_s^* \nabla \psi_s - \psi_s \nabla \psi_s^*\right) $

$ =\frac{i\hbar}{2\mu} \left[f(\theta) \frac{e^{ikr}}{r} \frac{\partial}{\partial r} \left( f^*(\theta) \frac{e^{-ikr}}{r}\right) - c.c.\right] $

$  = \frac{\hbar k}{\mu} \frac{|f(\theta)|^2}{r^2} $

+ $ \theta $角方向上单位立体角元$ d\Omega $中单位时间内出射的粒子数为：

$ dn = j_s r^2 d\Omega = \frac{\hbar k}{\mu}|f(\theta)|^2 d\Omega $

+ 因此，散射截面为：

$ \sigma(\theta) = \frac{1}{j_i} \left(\frac{dn}{d\Omega}\right) = |f(\theta)|^2 $

##### 结论
+ 经过计算，波函数为：

$ \psi(\vec{r}) = e^{i\vec{k}\cdot \vec{r}} - \frac{\mu}{2\pi \hbar^2} \int d^{3}r' \frac{e^{ik|\vec{r}-\vec{r}'|}}{|\vec{r}-\vec{r}'|} V(\vec{r}')\psi(\vec{r}') $

    - 可见，这是一个积分方程。

#### Born近似
+ $ \mathrm{Born} $近似中，我们将入射粒子和靶相互作用势$ V(\vec{r}) $看成微扰，而散射项就看成围绕。
+ 此时，$ \mathrm{Lippman-Schwinger} $方程中$ \psi(\vec{r}') $可以用$ e^{i\vec{k}\cdot\vec{r}'} $近似代替，得：

$ \psi(\vec{r}) = e^{i\vec{k}\cdot \vec{r}} - \frac{\mu}{2\pi \hbar^2} \int d^{3}r' \frac{e^{ik|\vec{r}-\vec{r}'|}}{|\vec{r}-\vec{r}'|} V(\vec{r}')e^{i\vec{k}\cdot\vec{r}'} $

    - 这就是势散射问题的$ \mathrm{Born} $一级近似解。
+ 考虑到有限的力程，上式右边的积分只局限于一个有限的区域，可以模仿电动力学的远场近似进行如下近似：

$ |\vec{r}-\vec{r}'|  = (r^2 - 2\vec{r}\cdot \vec{r}' + r'^2)^{1/2} \approx r(1-\vec{r}\cdot \vec{r}'/r^2)^{1/2} $

    - 由此，指数项可以进行进行近似：

$ e^{ik|\vec{r}-\vec{r}'|} \approx e^{ik r(1-\vec{r}\cdot \vec{r}'/r^2)^{1/2}} = e^{ikr-i\vec{k}_f \cdot \vec{r}'} $

        * 其中$ \vec{k}_f = k\vec{r}/r $，$ \hbar \vec{k}_f $为出射粒子的动量。
        * 根据弹性散射，应该有$ |\vec{k}_f| = |\vec{k}| = k $。
    - 此外，距离反比项也可以用场点距离倒数代替，即：

$ \frac{1}{|\vec{r}-\vec{r}'|} \approx \frac{1}{r}  $

    - 综上，可以得出散射波函数的近似结果：

$ \psi_{sc}(\vec{r}) =- \frac{\mu}{2\pi \hbar^2r} \int d^{3}r' e^{-i(\vec{k}-\vec{k}_f)\cdot \vec{r}'} V(\vec{r}')e^{i\vec{k}\cdot\vec{r}'} $

+ 与渐进行为相互比较：

$ \psi \rightarrow e^{ikz} +f(\theta)\frac{e^{ikr}}{r} $

    - 可以得到$ f(\theta,\varphi) $的表达式：

$ f(\theta,\varphi) = - \frac{\mu}{2\pi \hbar^2} \int d^{3}r' e^{-i(\vec{k}-\vec{k}_f)\cdot \vec{r}'} V(\vec{r}') $

    - 另外可以定义：

$ \vec{q} = \vec{k}_f - \vec{k} $

        * 根据$ \hbar \vec{q} $是散射过程中的动量转移，可以得到：

$ q = 2k \sin \frac{\theta}{2} $

    - 假设散射具有旋转对称性，可以进一步改写散射表达式：

$ f(\theta) = -\frac{2\mu}{\hbar^2 q}\int_0^{\infin}r'V(r')\sin qr'dr' $

    - 而散射截面为：

$ \sigma(\theta) = |f(\theta)|^2 = \frac{4\mu^2}{\hbar^4q^2}\left|\int_0^{\infin}r'V(r')\sin qr'dr'\right|^2 $



#### 全同粒子的散射
+ 在非全同的情境下，$ r\rightarrow \infin $时的渐进行为为：

$ \psi \rightarrow e^{ikz} +f(\theta)\frac{e^{ikr}}{r} $

+ 根据入射粒子和靶粒子的全同性种类要求，要对入射波和散射波分别进行对称化、反对称化还是不进行任何操作。散射波主要是处理$ f(\theta) $。

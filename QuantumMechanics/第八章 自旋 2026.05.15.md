### 电子自旋态与自旋算符
#### 电子的内禀自由度：自旋
+ 除了三维空间中的运动以外，电子具有内禀自由度：自旋。
+ 想要对电子状态进行完整的描述，还要给出自旋在某个给定方向上（例如$ z $轴方向）的投影的两个可能取值的波幅，即波函数中应该应该包含自旋投影$ s_z $这个变量。
    - 自旋投影$ s_z $的取值只能为：$ \pm \hbar/2 $。

#### 使用二分量波函数进行表示
+ 由此使用二分量波函数进行表示：

$ \psi(\vec{r},s_z)  = \begin{pmatrix}
\psi(\vec{r},\hbar/2)\\
\psi(\vec{r},-\hbar/2)
\end{pmatrix} $

    - $ |\psi(\vec{r},\hbar/2)|^2 $为电子位于$ \vec{r} $且自旋投影$ s_z = \hbar/2 $的概率。
    - $ |\psi(\vec{r},-\hbar/2)|^2 $为电子位于$ \vec{r} $且自旋投影$ s_z = -\hbar/2 $的概率。
    - $ \int d^3 r |\psi(\vec{r},\hbar/2)|^2 $为电子自旋投影为$ s_z = \hbar/2 $的概率。
    - $ \int d^3 r |\psi(\vec{r},-\hbar/2)|^2 $为电子自旋投影为$ s_z = -\hbar/2 $的概率。
+ 归一化条件为：

$ \int d^3 r [|\psi(\vec{r},\hbar/2)|^2+|\psi(\vec{r},-\hbar/2)|^2] = 1 $

#### 可以分离变量的情形
+ 如果系统$ \mathrm{Hamilton} $量中空间坐标部分与自旋变量部分可以分开，那么波函数可以分离变量：

$ \psi(\vec{r},s_z)  = \phi(\vec{r}) \chi(s_z) $

+ 其中$ \chi(s_z) $是自旋波函数，其一般形式为：

$ \chi(s_z) = \begin{pmatrix}a\\b\end{pmatrix} $

    - 此时归一化条件可以写为：

$ \chi^{\dagger}(s_z)\chi(s_z) = \begin{pmatrix}a^*&b^*\end{pmatrix} \begin{pmatrix}a\\b\end{pmatrix} = |a|^2+|b|^2=1 $

#### 自旋角动量z轴投影算符本征态
+ 自旋向上（$ s_z = \hbar/2 $）的本征态为：

$ \alpha = \chi_{1/2}(s_z) = \begin{pmatrix}1\\0 \end{pmatrix} $

+ 自旋向下（$ s_z = -\hbar/2 $）的本征态为：

$ \beta = \chi_{-1/2}(s_z) = \begin{pmatrix}0\\1 \end{pmatrix} $

+ 由此可以用来展开一般的自旋态：

$ \chi(s_z) = \begin{pmatrix}a\\b\end{pmatrix} = a\alpha + b\beta $

    - 波函数表示为：

$ \psi(\vec{r},s_z)  = 
\psi(\vec{r},\hbar/2)\alpha+\psi(\vec{r},-\hbar/2)\beta $

#### 电子自旋算符与Pauli矩阵
+ 考虑到自旋具有角动量特征，那么期待：

$ [s_\alpha,s_\beta] = i\hbar \epsilon_{\alpha\beta\gamma}s_\gamma $

$ s_\alpha^{\dagger} = s_\alpha $

+ 此时可以引入$ \mathrm{Pauli} $算符$ \vec{\sigma} $：

$ \vec{s} = \frac{\hbar}{2}\vec{\sigma} $

    - 那么可以推出：

$ [\sigma_\alpha,\sigma_\beta] = 2i \epsilon_{\alpha\beta\gamma}\sigma_\gamma $

$ \sigma_\alpha^{\dagger} = \sigma_\alpha $

    - 因为$ \vec{s} $沿着任何方向投影只能取$ \pm \hbar/2 $两个值中的一个
    - 所以$ \vec{\sigma} $沿着任何方向投影只能取$ \pm1 $两个值中的一个，由此可知任何一个方向投影算符的平方均为单位算符：

$ \sigma_\alpha^2 = \hat{I} $

+ 我们首先考虑一个例子：

$ \sigma_y \sigma_z - \sigma_z \sigma_y = 2i\sigma_x $

    - 用$ \sigma_y $左乘和右乘这个式子：

$  \sigma_z -\sigma_y \sigma_z \sigma_y = 2i\sigma_y\sigma_x $

$ \sigma_y \sigma_z \sigma_y- \sigma_z  = 2i\sigma_x\sigma_y $

    - 两边相加得：

$ \sigma_x\sigma_y+\sigma_y\sigma_x  = 0 $

    - 结合对易关系：

$ \sigma_x\sigma_y-\sigma_y\sigma_x  = 2i\sigma_z $

    - 可以得到：

$ \sigma_x \sigma_y = -\sigma_y \sigma_x = i \sigma_z $

        * 即：

$ \sigma_\alpha\sigma_\beta = \delta_{\alpha \beta} +i\epsilon_{\alpha\beta\gamma}\sigma_{\gamma} $

+ 综上，$ \mathrm{Pauli} $**矩阵的代数性质**为：

$ \boxed{\sigma_\alpha\sigma_\beta = \delta_{\alpha \beta} +i\epsilon_{\alpha\beta\gamma}\sigma_{\gamma}} $

$ \boxed{\vec{\sigma}^{\dagger} = \vec{\sigma}} $

+ 此外可以推出，在$ z $方向上的矩阵表达式为：

$ \boxed{\sigma_x = \begin{pmatrix}
0&1\\
1&0
\end{pmatrix},\sigma_y = \begin{pmatrix}
0&-i\\
i&0
\end{pmatrix},\sigma_z = \begin{pmatrix}
1&0\\
0&-1
\end{pmatrix}} $

### 总角动量本征态
#### 自旋轨道耦合
+ 电子自旋是一种相对论效应，在中心库仑场$ V(r) $中运动的电子的相对论性波动方程，在非相对论极限下，
+ $ \mathrm{Hamilton} $量会出现一项自旋轨道相互作用：

$ \xi(r)\vec{s}\cdot\vec{l} $

$ \xi(r) = \frac{1}{2\mu^2 c^2} \frac{1}{r}\frac{dV}{dr} $

    - 强磁场下，这一项的影响可以忽略，例如正常$ \mathrm{Zeeman} $效应。
    - 弱磁场下不可以忽略。

#### 寻找对易守恒量完全集
+ 中心力场下，考虑到自旋-轨道耦合作用：
    - 轨道角动量$ \vec{l} $，自旋角动量$ \vec{s} $不与$ \hat{H} $中的$ \xi(r)\vec{s}\cdot\vec{l} $对易，不是守恒量。
    - 总角动量$ \vec{j} $与$ \xi(r)\vec{s}\cdot\vec{l} $对易，是守恒量。
    - $ j^2 $乃至轨道角动量平方$ l^2 $以及自旋角动量平方$ s^2 = 3\hbar^2/4 $都是守恒量。
+ 综上，可以选择对易守恒量完全集：

$ (H,l^2,j^2,j_z) $

#### 共同本征函数
+ 设共同本征态的二分量波函数为：

$ \phi(\theta, \varphi, s_z) = \begin{pmatrix} \phi(\theta, \varphi, \hbar/2) \\ \phi(\theta, \varphi, -\hbar/2) \end{pmatrix} \equiv \begin{pmatrix} \phi_1(\theta, \varphi) \\ \phi_2(\theta, \varphi) \end{pmatrix}  $

+ 约束1：二分量波函数应该是$ j_z $的本征态：

$ j_z\begin{pmatrix} \phi_1 \\ \phi_2 \end{pmatrix} =  l_z \begin{pmatrix} \phi_1 \\ \phi_2 \end{pmatrix} + \frac{\hbar}{2} \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix} \begin{pmatrix} \phi_1 \\ \phi_2 \end{pmatrix} = j_z' \begin{pmatrix} \phi_1 \\ \phi_2 \end{pmatrix} $

    - 由此得出：

$ \begin{cases} l_z \phi_1 = (j_z' - \hbar/2) \phi_1 \\ l_z \phi_2 = (j_z' + \hbar/2) \phi_2 \end{cases} $

    - 这说明$ \phi_1,\phi_2 $都是$ l_z $的本征态，

$ \phi(\theta, \varphi, s_z) = \begin{pmatrix} a Y_{lm}(\theta, \varphi) \\ b Y_{l,m+1}(\theta, \varphi) \end{pmatrix}  $

        * 注意，此处只要求每个分量都是$ l_z $的本征态，但对应的本征值不同
        * 这样合在一起的二分量波函数就不是$ l_z $的本征态了。
        * 这也是合理的，因为$ l_z $不是守恒量。
    - 下面需要计算$ a,b $的数值。
+ 约束2：二分量波函数应该是$ j^2 $的本征态：
    - 在 Pauli 表象中，$ j^2 = l^2 + s^2 + 2\mathbf{s} \cdot \mathbf{l} $：

$ j^2 = \begin{bmatrix} l^2 + 3\hbar^2/4 + \hbar l_z & \hbar l_- \\ \hbar l_+ & l^2 + 3\hbar^2/4 - \hbar l_z \end{bmatrix} $

    - 其中 $ l_{\pm} = l_x \pm i l_y $。
+ 利用 $ l_{\pm} Y_{lm} = \hbar \sqrt{(l \pm m + 1)(l \mp m)} Y_{l, m\pm 1} $，得到线性方程组：

$ \begin{cases} [l(l+1) + 3/4 + m]a + \sqrt{(l-m)(l+m+1)}b = \lambda a \\ \sqrt{(l-m)(l+m+1)}a + [l(l+1) + 3/4 - (m+1)]b = \lambda b \end{cases} $

    - 这是一个线性齐次方程，可以找到$ a,b $的非平凡解的条件为：

$ \begin{vmatrix} l(l+1) + 3/4 + m - \lambda & \sqrt{(l-m)(l+m+1)} \\ \sqrt{(l-m)(l+m+1)} & l(l+1) + 3/4 - m - 1 - \lambda \end{vmatrix} = 0 $ 

    - 解得：

$ \lambda_1 = (l+1/2)(l+3/2), \quad \lambda_2 = (l-1/2)(l+1/2) $

    - 即：

$ \lambda = j(j+1),\;\;j = l \pm 1/2 $ 

+ 将$ j = l + 1/2 $代入原来的方程后可以得到：

$ \frac{a}{b} = \sqrt{\frac{l+m+1}{l-m}} $

    - $ (H,l^2,j^2,j_z) $共同本征二分量波函数为：

$ \boxed{\phi(\theta, \varphi, s_z) = \frac{1}{\sqrt{2l+1}} \begin{pmatrix} \sqrt{l+m+1} Y_{lm} \\ \sqrt{l-m} Y_{l,m+1} \end{pmatrix} ,\;\; j = l+1/2} $

+ 将$ j = l - 1/2 $代入原来的方程后可以得到：

$ \frac{a}{b} = -\sqrt{\frac{l-m}{l+m+1}} $

    - $ (H,l^2,j^2,j_z) $共同本征二分量波函数为：

$ \boxed{\phi(\theta, \varphi, s_z) = \frac{1}{\sqrt{2l+1}} \begin{pmatrix} -\sqrt{l-m} Y_{lm} \\ \sqrt{l+m+1} Y_{l,m+1} \end{pmatrix} ,\;\; j = l+1/2} $

### 碱金属原子
#### 碱金属原子光谱的双线结构
+ 碱金属原子（如 Li, Na, K）具有一个价电子，其受原子核和内层电子（原子实）的屏蔽库仑场 $ V(r) $ 作用。考虑到电子自旋与轨道运动的相互作用，价电子的哈密顿量 $ H $为：

$ H = \frac{p^2}{2\mu} + V(r) + \xi(r) \mathbf{s \cdot l} \quad \dots (1) $

+ 其中，自旋-轨道耦合强度因子 $ \xi(r) $ 定义为：

$ \xi(r) = \frac{1}{2\mu^2 c^2} \frac{1}{r} \frac{dV}{dr} \quad \dots (1) $

##### 算符作用与本征态
+ 为了求解能级，选取对易守恒量完全集 $ (H, \mathbf{l^2}, \mathbf{j^2}, j_z) $ 的共同本征态 $ \psi $：

$ \psi(r, \theta, \varphi, s_z) = R(r) \phi_{ljm_j}(\theta, \varphi, s_z) \quad \dots (2) $

+ 根据算符 $ \mathbf{s \cdot l} $ 作用于 $ \phi_{ljm_j} $ 的结果（式 23）：

$ (\mathbf{s \cdot l}) \phi_{ljm_j} = \begin{cases} \frac{\hbar^2}{2} l \phi_{ljm_j}, & j = l + 1/2 \\ -\frac{\hbar^2}{2} (l+1) \phi_{ljm_j}, & j = l - 1/2 \quad (l \neq 0) \end{cases} \quad \dots (23) $

+ 此外，$ \sigma_z $ 在该态下的平均值为：

$ \langle ljm_j | \sigma_z | ljm_j \rangle = \begin{cases} m_j / j, & j = l + 1/2 \\ -m_j / (j+1), & j = l - 1/2 \quad (l \neq 0) \end{cases} \quad \dots (24) $

##### 径向方程与能级分裂
+ 将波函数代入能量本征方程（式 3）：

$ \left[ -\frac{\hbar^2}{2\mu} \left( \frac{1}{r^2} \frac{\partial}{\partial r} r^2 \frac{\partial}{\partial r} - \frac{\mathbf{l^2}}{\hbar^2 r^2} \right) + V(r) + \xi(r) \mathbf{s \cdot l} \right] \psi = E\psi \quad \dots (3) $

+ 由此导出不同 $ j $ 值的**径向方程**：
    - 对于 $ j = l + 1/2 $：

$ \left[ -\frac{\hbar^2}{2\mu} \frac{1}{r^2} \frac{d}{dr} r^2 \frac{d}{dr} + V(r) + \frac{l(l+1)\hbar^2}{2\mu r^2} + \frac{l\hbar^2}{2} \xi(r) \right] R(r) = E R(r) \quad \dots (4) $

    - 对于 $ j = l - 1/2 \ (l \neq 0) $：

$ \left[ -\frac{\hbar^2}{2\mu} \frac{1}{r^2} \frac{d}{dr} r^2 \frac{d}{dr} + V(r) + \frac{l(l+1)\hbar^2}{2\mu r^2} - \frac{(l+1)\hbar^2}{2} \xi(r) \right] R(r) = E R(r) \quad \dots (5) $

    - 由于 $ V(r) $ 非纯库仑场，能量本征值 $ E_{nlj} $ 与量子数 $ n, l, j $ 均有关。且有：

$ E_{n, l, j=l+1/2} > E_{n, l, j=l-1/2} \quad \dots (6) $

        * 这说明 $ j=l+1/2 $ 的能级略高于 $ j=l-1/2 $ 的能级，其差值为 $ \Delta E $。

##### 实例：钠（Na）原子的双线结构
+ **电子排布：**$ (1s)^2 (2s)^2 (2p)^6 (3s)^1 $，价电子处于 $ 3s $ 态。
+ **分裂情况：** 当价电子跃迁至 $ 3p $ 能级时，受自旋-轨道耦合影响，$ 3p $ 分裂为 $ 3p_{3/2} $ 和 $ 3p_{1/2} $。
+ **光谱双线（D线）：**
    - $ 3p_{3/2} \to 3s_{1/2} $：发射波长 $ \lambda = 589.0 \text{ nm} $ 的光（称为 $ D_2 $ 线）。
    - $ 3p_{1/2} \to 3s_{1/2} $：发射波长 $ \lambda = 589.6 \text{ nm} $ 的光（称为 $ D_1 $ 线）。

#### 反常Zeeman效应
##### 核心内容概括
1. **正常 Zeeman 效应（强磁场）**：

在强磁场下，自旋-轨道耦合可以忽略。体系的 $ \mathrm{Hamiltonian} $（哈密顿量）由动能、势能及磁场相互作用项组成。磁场导致能级按磁量子数 $ m $ 进行简并解除，分裂为 3 条光谱线。

2. **反常 Zeeman 效应（弱磁场）**：

在弱磁场下，自旋-轨道耦合（$ L-S $ 耦合）不可忽略。此时总角动量 $ \mathbf{j} = \mathbf{l} + \mathbf{s} $ 才是守恒量。能级的分裂不再简单地依赖于 $ m $，而是依赖于总角动量磁量子数 $ m_j $，导致光谱线数多于 3 条，呈现“反常”现象。

3. **物理机制**：

由于磁场不仅作用于轨道磁矩，还作用于电子的自旋内禀磁矩，且两者的旋磁比不同，磁场导致的能量移动取决于总角动量在磁场方向的分量。

---

##### 强磁场下的哈密顿量与能量 (正常 Zeeman 效应)
+ 当自旋-轨道耦合被略去时，$ \mathrm{Hamiltonian} $为：

$ H = p^2/2\mu + V(r) + \frac{eB}{2\mu c}(l_z + 2s_z) \tag{7} $

+ 其**共同本征态**为：

$ \psi_{nlm m_s}(r, \theta, \varphi, s_z) = \psi_{nlm}(r, \theta, \varphi)\chi_{m_s}(s_z) = R_{nl}(r)Y_{lm}(\theta, \varphi)\chi_{m_s}(s_z) \tag{8} $

+ 相应的**能量本征值**为：

$ E_{nlm m_s} = E_{nl} + \frac{eB}{2\mu c}\hbar(m + 2m_s), \quad m_s = \pm 1/2 $

+ 对于不考虑自旋的情形，能级差为：

$ E_{nlm m_s} = E_{nl} + \frac{eB}{2\mu c}\hbar(m \pm 1) \tag{9} $

##### 弱磁场下的哈密顿量 (反常 Zeeman 效应)
+ 当自旋-轨道耦合项 $ \xi(r)\mathbf{s} \cdot \mathbf{l} $ 必须考虑时，$ \mathrm{Hamiltonian} $为：

$ H = p^2/2\mu + V(r) + \xi(r)\mathbf{s} \cdot \mathbf{l} + \frac{eB}{2\mu c}(l_z + 2s_z) \tag{10} $

+ 利用 $ \mathbf{j} = \mathbf{l} + \mathbf{s} $，上式可改写为：

$ H = p^2/2\mu + V(r) + \xi(r)\mathbf{s} \cdot \mathbf{l} + \frac{eB}{2\mu c}j_z + \frac{eB}{2\mu c}s_z \tag{10} $

+ 本征态与能量修正：在略去式$ (10) $最后的小项干扰后，本征态表示为：

$ \psi_{nljm_j}(r, \theta, \varphi, s_z) = R_{nlj}(r)\phi_{ljm_j}(\theta, \varphi, s_z) \tag{11} $

+ 能量本征值为：

$ E_{nljm_j} = E_{nlj} + m_j \hbar \omega_L, \quad \omega_L = eB/2\mu c \tag{12} $

    - 此处 $ \omega_L $ 为拉莫尔频率
    - 分裂出的能级数为 $ 2j+1 $ 条（因为$ j $是半整数，所以$ 2j+1 $是一个偶数）
    - 这解释了反常$ \mathrm{Zeeman} $分裂现象

### 多电子体系的自旋态
#### 总角动量算符
+ 定义两个电子的总角动量算符：

$ \mathbf{S} = \mathbf{s}_1 + \mathbf{s}_2 \tag{1} $

    - 它应该有角动量算符的一般性质：

$ [S_x, S_y] = i\hbar S_z, \quad [S_y, S_z] = i\hbar S_x, \quad [S_z, S_x] = i\hbar S_y \tag{2} $

$ S^2 = S_x^2 + S_y^2 + S_z^2 \tag{3} $

$ [S^2, S_\alpha] = 0, \quad \alpha = x, y, z \tag{4} $

#### **求总角动量平方算符**$ S^2 $**的本征函数**
+ **<font style="color:#DF2A3F;">我们希望求出总角动量平方算符</font>**$ S^2 $**<font style="color:#DF2A3F;">的本征函数。</font>**
    - 可以考虑展开：

$ S^2 = (\mathbf{s}_1 + \mathbf{s}_2)^2 = s_1^2 + s_2^2 + 2\mathbf{s}_1 \cdot \mathbf{s}_2 $

$ = \frac{3}{2}\hbar^2 + \frac{\hbar^2}{2}(\sigma_{1x}\sigma_{2x} + \sigma_{1y}\sigma_{2y} + \sigma_{1z}\sigma_{2z}) \tag{6} $

    - 注意$ \sigma_{1x}\sigma_{2x} $并不是矩阵相乘的意思，二者应该分别作用在第一个粒子的旋量、第二个粒子的旋量上。
    - 因此其实是$ \sigma_{1x}\otimes\sigma_{2x} $的意思。



$ \sigma_y \alpha = i\beta, \quad \sigma_y \beta = -i\alpha, \quad \sigma_x \alpha = \beta, \quad \sigma_x \beta = \alpha, \quad \sigma_z \alpha = \alpha, \quad \sigma_z \beta = -\beta \tag{7} $

并注意 $ \sigma_1 $ 和 $ \sigma_2 $ 分别作用于第一和第二个电子的自旋波函数上, 容易证明

$ \begin{cases} 
S^2 \alpha(1)\alpha(2) = 2\hbar^2 \alpha(1)\alpha(2) \\
S^2 \beta(1)\beta(2) = 2\hbar^2 \beta(1)\beta(2) 
\end{cases} \tag{8} $

+ 即 $ \alpha(1)\alpha(2) $ 和 $ \beta(1)\beta(2) $ 已经是 $ S^2 $ 本征态. 但对于 $ S_z = 0 $ 的两个本征态 $ \alpha(1)\beta(2) $ 与 $ \beta(1)\alpha(2) $ 则否. 然而我们可以把这两个态线性叠加, 以构成 $ S^2 $ 的本征态, 令

$ \chi = c_1 \alpha(1)\beta(2) + c_2 \beta(1)\alpha(2) \tag{9} $

+ 要求它是 $ S^2 $ 的本征态, 即

$ S^2 \chi = \lambda \hbar^2 \chi \tag{10} $

+ $ \lambda $ (无量纲) 待定. 利用式$ (6) $与式$ (7) $，不难得出：

  
$ S^2 \chi = \hbar^2 (c_1 + c_2)\alpha(1)\beta(2) + \hbar^2 (c_1 + c_2)\beta(1)\alpha(2) 
 $

$ = \lambda \hbar^2 [c_1 \alpha(1)\beta(2) + c_2 \beta(1)\alpha(2)] $

+ 由此可得出

$ 
\begin{cases}
(1 - \lambda)c_1 + c_2 = 0 \\
c_1 + (1 - \lambda)c_2 = 0
\end{cases} \tag{11} $

+ 此方程组有非平庸解的条件为

$ \begin{vmatrix}
1 - \lambda & 1 \\
1 & 1 - \lambda
\end{vmatrix} = 0 \tag{12} $

+ 解之, 得两根, $ \lambda = 0, 2 $. 
    - $ \lambda = 0 $ 根代入式 (11) 中任何一式，可得 $ c_1 / c_2 = -1 $.
    - $ \lambda = 2 $ 根代入式 (11) 中任何一式，可得 $ c_1 / c_2 = 1 $.
+ 再利用归一化条件, 并取适当相位, 可求出 $ S^2 $ 的归一化本征态为

$ \begin{cases}
\frac{1}{\sqrt{2}} [\alpha(1)\beta(2) - \beta(1)\alpha(2)] & (S^2 \text{ 本征值为 } 0) \\
\frac{1}{\sqrt{2}} [\alpha(1)\beta(2) + \beta(1)\alpha(2)] & (S^2 \text{ 本征值为 } 2\hbar^2)
\end{cases} \tag{13} $

+ 令 $ S^2 $ 本征值记为 $ S(S+1)\hbar^2 $, 则以上两个态分别相当于 $ S=0 $ 和 $ 1 $
+  联合式$ (8) $与式$ (13) $，就求出了 $ (S^2, S_z) $ 的共同本征态，记为 $ \chi_{SM_S} $. $ S=1, M_S = \pm 1, 0 $ 的三个态称为自旋三重态 (triplet), 而 $ S=0, M_S = 0 $ 的态称为自旋单态 (singlet).

#### 耦合表象与非耦合表象
+ 非耦合表象：

$ \alpha(1)\alpha(2) = |\uparrow\rangle_1|\uparrow\rangle_2 $

$ \alpha(1)\beta(2) = |\uparrow\rangle_1|\downarrow\rangle_2 $

$ \beta(1)\alpha(2) = |\downarrow\rangle_1|\uparrow\rangle_2 $

$ \beta(1)\beta(2) = |\downarrow\rangle_1|\downarrow\rangle_2 $

+ 耦合表象：$ \chi_{SM_S} $，$ S $代表总角动量量子数，$ M_S $代表总角动量对应的磁量子数。

$ \chi_{00} = \frac{1}{\sqrt{2}}[|\uparrow\rangle_1|\downarrow\rangle_2 - |\downarrow\rangle_1|\uparrow\rangle_2] $（单态，纠缠态）

$ \chi_{10} = \frac{1}{\sqrt{2}}[|\uparrow\rangle_1|\downarrow\rangle_2 + |\downarrow\rangle_1|\uparrow\rangle_2] $（三重态，纠缠态）

$ \chi_{11} = |\uparrow\rangle_1|\uparrow\rangle_2 $（三重态，可分离态）

$ \chi_{1-1} = |\downarrow\rangle_1|\downarrow\rangle_2 $（三重态，可分离态）

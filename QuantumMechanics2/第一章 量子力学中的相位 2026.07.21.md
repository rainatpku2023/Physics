### Berry相
#### 知识回顾：量子绝热近似
+ 在[《量子力学（A）》课程](https://dengbaiyu2023.yuque.com/org-wiki-dengbaiyu2023-vsgo6q/lzpma1/wg5h98r7oodt4oct#nu83C)中，在哈密顿量含时的情况下，我们将状态$ \ket{\psi(t)} $写成瞬时本征态$ \ket{n(t)} $的线性叠加：

$ \ket{\psi(t)} = \sum_n a_n(t) \exp \left[-\frac{i}{\hbar} \int_0^{t} E_n(t')dt'\right]\ket{n(t)} $

+ 量子绝热定理说：
    - 如果体系的哈密顿量$ \hat{H}(t) $变化的足够缓慢，且初态为$ \ket{\psi(0)} = \ket{m(0)} $，那么$ t>0 $时刻体系会保持在$ \hat{H}(t) $相应的瞬时本征态$ \ket{m(t)} $上。
    - 也就是说近似不会发生从$ \ket{m} $到$ \ket{m'},m' \neq m $的跃迁。
+ 之后还导出，前面的叠加系数的表达式：

$ \dot a_m(t) =-\sum_n a_n(t) \exp \left[-\frac{i}{\hbar} \int_{0}^{t}E_n(\tau)-E_m(\tau)d\tau\right] \braket{{m}(t)|\dot n(t)}
 $

$ = -a_m \braket{m(t)|\dot m(t)}-
\sum_{n\neq m} a_n(t) \exp \left[-\frac{i}{\hbar} \int_{0}^{t}E_n(\tau)-E_m(\tau)d\tau\right] \braket{{m}(t)|\dot n(t)} $

    - 量子绝热定理要求积分后右侧第二项贡献可以忽略，具体来说就是：

$ \beta = \left| \frac{\hbar \braket{m|\dot{n}}}{E_m - E_n}\right| \ll 1 $

+ **忽略掉第二项，并假设初态为**$ \ket{\psi(0)} = \ket{m(0)} $，表达式简化为：

$ \dot a_m(t) =- \braket{m(t)|\dot m(t)} a_m(t) $

    - 结合初始条件$ a_m(0)=1 $，可以通过积分得到：

$ a_m(t) = \exp \left[-\int_0^t \braket{m(t')|\dot m(t')}dt'\right]a_m(0) $

    - 代入原来的表达式，得到：

$ \ket{\psi(t)} =  a_m(0) \exp \left[-\int_0^t \braket{m(t')|\dot m(t')}dt'\right]\exp \left[-\frac{i}{\hbar} \int_0^{t} E_m(t')dt'\right]\ket{m(t)} $

$ \boxed{\ket{\psi(t)}:= e^{i[\alpha_m(t)+\gamma_m(t)]}\ket{m(t)}} $

+ 其中：

$ \boxed{\alpha_m(t) = -\frac{1}{\hbar} \int_0^t E_m(t')dt'} $

$ \boxed{\gamma_m(t) = i\int_0^t \braket{m(t')|\dot m(t')}dt'} $

    - 分别是动力学相和几何相。

#### Berry几何相的假设
+ $ \mathrm{Berry} $几何相有两个假设：
    - 哈密顿量$ \hat{H} = \hat{H}(\vec{R}(t)) $依赖于含时参量$ \vec{R}(t) $且周期演化，周期为$ \tau $。
        * 即$ \vec{R}(\tau) =\vec{R}(0) $，$ \hat{H}(\vec{R}(\tau)) = \hat{H}(\vec{R}(0)) $。
    - 哈密顿量随着时间变化足够缓慢，即量子绝热定理成立。

#### Berry几何相与动力学相
+ 假设初始时刻：

$ \ket{\psi(0)} = \ket{m(\vec{R}(0))} $

+ 此时，态演化可以借用之前的相位分解方法：

$ \ket{\psi(t)}= e^{i[\alpha_m(t)+\gamma_m(t)]}\ket{m(\vec{R}(t))} $

$ \alpha_m(t) = -\frac{1}{\hbar} \int_0^t E_m(\vec{R}(t'))dt' $

$ \gamma_m(t) = i\int_0^t \braket{m(\vec{R}(t'))|\dot m(\vec{R}(t'))}dt' $

    - $ \gamma_m(t) $被称为$ \mathrm{Berry} $几何相，$ \alpha_m(t) $被称为动力学相。

#### 一个周期内的相位变化
+ 对于一个周期$ \tau $的循环过程，$ \mathrm{Berry} $几何相可以做如下推导：

$ \gamma_m(\tau) = i\int_0^\tau \braket{m(\vec{R}(t))|\dot m(\vec{R}(t))}dt
=i\int_0^\tau \braket{m(\vec{R}(t))|\frac{\partial}{\partial t}|m(\vec{R}(t))}dt $

$ =i\int_0^\tau \braket{m(\vec{R}(t))|\nabla_{\vec{R}}|m(\vec{R}(t))}\cdot \frac{d\vec{R}}{dt}\cdot dt $

$ =i\int_{\vec{R}(0)}^{\vec{R}(\tau)} \braket{m(\vec{R}(t))|\nabla_{\vec{R}}|m(\vec{R}(t))}\cdot d\vec{R} $

    - 第一行到第二行用到了复合函数求导的链式法则。
    - 观察到积分上下限的位置相同，可以改写为：

$ \gamma_m(C)  = \gamma_m(\tau) = \oint_C \vec{A}_m(\vec{R})\cdot d\vec{R} $

    - 其中

$ \vec{A}_m(\vec{R}):= i\braket{m(\vec{R})|\nabla_{\vec{R}}|m(\vec{R})} $

        * 是参数$ \vec{R} $空间中的矢势。注意是参数空间而非位形空间。
        * $ C $是回路的代称。
    - 根据$ \mathrm{Stokes} $定理，可以改写为参数空间中的面积分：

$ \gamma_m(C)  = \gamma_m(\tau) = \iint_C \vec{B}_m(\vec{R})\cdot d\vec{S} = \Phi_m $

    - 其中

$ \vec{B}_m(\vec{R}):= \nabla_{\vec{R}} \times \vec{A}_m(\vec{R}) $

        * 是参数空间中的磁感应强度，$ \Phi_m $是参数空间中的磁通量。
        * 正是因为磁通量这样一种具有几何直观的解释，$ \gamma_m $被称为“几何相”。

### Aharonov-Anandan相
#### AA相的假设
+ $ \mathrm{Aharonov-Anandan} $相位：
    - 放弃了绝热近似假定。
    - 不要求哈密顿量$ \hat{H}(t) $呈现周期性演化。
    - 假定了体系的量子态$ \ket{\psi(t)} $按照$ \mathrm{Schr\ddot{o}dinger} $方程演化，周期为$ \tau $。
+ 值得注意的是，波函数附加一个纯相位并不改变量子态。

#### AA几何相与动力学相
+ 根据假设，量子态以$ \tau $为周期进行演化，那么有：

$ \ket{\psi(\tau)} = e^{i\phi}\ket{\psi(0)} $

    - 波函数附加一个纯相位并不改变量子态，所以$ \ket{\psi(\tau)} $和$ \ket{\psi(0)} $是同一个量子态。
+ 我们希望将相位差分离出去，因此做含时相位变换：

$ \ket{\psi(t)} = e^{if(t)}\ket{\tilde{\psi}(t)} $

    - 其中$ f(\tau) - f(0) = \phi $，这样就可以实现相位差的分离：

$ \ket{\tilde{\psi}(\tau)}=\ket{\tilde{\psi}(0)} $

+ 将含时相位变换的表达式代入$ \mathrm{Schr\ddot{o}dinger} $方程，得到：

$ LHS = i\hbar\frac{\partial}{\partial t}\ket{\psi (t)} = i\hbar\frac{\partial}{\partial t}\left[e^{if(t)}\ket{\tilde{\psi} (t)}\right] = i\hbar i\dot f e^{if(t)}\ket{\tilde{\psi}(t)}+e^{if(t)}i\hbar \frac{\partial}{\partial t}\ket{\tilde{\psi}(t)}
 $

$ =-\hbar \dot{f} \ket{\psi(t)} +e^{if(t)}i\hbar \frac{\partial}{\partial t}\ket{\tilde{\psi}(t)}
 $

$ RHS = \hat{H}(t)\ket{\psi(t)} $

    - 两侧分别左乘$ \bra{\psi(t)} $，可以得到：

$ LHS =-\hbar \dot{f}\braket{\psi(t)|\psi(t)} +\bra{\tilde \psi(t)}e^{-if(t)}e^{if(t)}i\hbar \frac{\partial}{\partial t}\ket{\tilde{\psi}(t)} $

$ = - \hbar \dot{f}+i\hbar\bra{\tilde \psi(t)} \frac{\partial}{\partial t}\ket{\tilde{\psi}(t)} $

$ RHS = \braket{\psi(t)|\hat{H}(t)|\psi(t)} $

    - 左右两侧相等，得到：

$ - \hbar \dot{f}+i\hbar\bra{\tilde \psi(t)} \frac{\partial}{\partial t}\ket{\tilde{\psi}(t)} = \braket{\psi(t)|\hat{H}(t)|\psi(t)} $

$ \Rightarrow \dot f = i\braket{\tilde \psi(t)| \frac{\partial}{\partial t}|\tilde{\psi}(t)} - \frac{1}{\hbar}\braket{\psi(t)|\hat{H}(t)|\psi(t)} $

    - 两侧对时间$ t $积分一个周期$ \tau $，得到：

$ f(\tau)-f(0) = \int_0^\tau dt \braket{\tilde \psi(t)| i\frac{\partial}{\partial t}|\tilde{\psi}(t)} +  \int_0^\tau dt \braket{\psi(t)|\frac{-\hat{H}(t)}{\hbar}|\psi(t)} $

+ 也就是说：

$ \phi = f(\tau)-f(0) = \alpha(\tau)+\gamma(\tau) $

$ \alpha(\tau) := \int_0^\tau dt \braket{\psi(t)|\frac{-\hat{H}(t)}{\hbar}|\psi(t)} $

$ f(\tau)-f(0) = \int_0^\tau dt \braket{\tilde \psi(t)| i\frac{\partial}{\partial t}|\tilde{\psi}(t)} +  \int_0^\tau dt \braket{\psi(t)|\frac{-\hat{H}(t)}{\hbar}|\psi(t)} $

    - 其中$ \alpha(\tau) $是动力学相，$ \gamma(\tau) $是几何相，又被称为$ \mathrm{AA} $相。
    - 值得注意的是，$ \gamma(\tau) $计算公式用到的是$ \ket{\tilde \psi(t)} $而非$ \ket{\psi(t)} $，这一般是很难事先知道的，所以一般使用下面的公式进行计算：

$ \gamma(\tau) = \phi - \alpha(\tau) $

### Berry相和Aharonov-Anandan相的关系
+ $ \mathrm{AA} $动力学相位的定义为：

$ \alpha(\tau) := \int_0^\tau dt \braket{\psi(t)|\frac{-\hat{H}(t)}{\hbar}|\psi(t)} $

    - 此时并未假定量子绝热定理成立，也没有假定哈密顿量随着试卷周期性变化。
    - 但是<font style="color:#DF2A3F;">如果量子绝热定理成立，哈密顿量随着时间变化</font>，$ \ket{\psi(t)} $应该是同一个瞬时本征态，也就是说：

$ \alpha(\tau) = \int_0^\tau dt \braket{\psi(t)|\frac{-\hat{H}(t)}{\hbar}|\psi(t)} = \int_0^\tau dt \braket{m(t)|\frac{-\hat{H}(t)}{\hbar}|m(t)}  $

$ = -\frac{1}{\hbar} \int_0^\tau dt \braket{m(t)|\hat{H}(t)|m(t)} = -\frac{1}{\hbar} \int_0^\tau E_m(t)dt = \alpha_m(\tau) $

        * 即此时$ \mathrm{AA} $动力学相与$ \mathrm{Berry} $动力学相是相同的。
